# 太空環境與光照說明

最後更新：2026-10-27

背景改成太空（2026-10-27 稍後加上星空天空盒，見 [星空說明.md](星空說明.md)），所有天體（包括衛星）的光都從太陽的位置照過來，不再依賴場景裡的 Directional Light。

| 項目 | 原本 | 現在 |
| --- | --- | --- |
| 背景 | Main Camera 的 Clear Flags = Skybox，畫 Unity 預設的灰藍色天空 | 星空天空盒（`StarrySky/Starfield`）；關掉星空時是純黑 |
| 環境光 | 從天空盒取樣，背光面泛灰藍 | 幾乎全黑的單一顏色 |
| 太陽、八大行星 | 自訂 Shader，光從太陽位置來（已經是對的） | 不變 |
| 衛星（純色球） | URP 預設 Lit 材質，被 Directional Light 從同一個方向照亮 | `StarrySky/SimpleBody`：光從太陽位置來 |
| Directional Light | 開著（只照得到衛星） | Play 時關掉 |

## 2. 怎麼看

按 Play 就會生效，不用設定。在 **Simulator > SolarSystemBuilder > 外觀**：

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| Space Environment | 開 | 關掉 = 回到原本的天空背景與 Directional Light（要在按 Play 前設定） |
| Plain Body Material | 空 | 衛星用的材質；留空 = 讀 `Resources/Materials/SimpleBody` |

Play 中在 Simulator 上會多一個 **SpaceEnvironment** 元件，可以即時調：

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| Starfield / Star Brightness / Milky Way | 開 / 1 / 1 | 星空天空盒，見 [星空說明.md](星空說明.md) |
| Background Color | 黑 | 關掉星空時的相機背景色 |
| Ambient Color | (0.01, 0.01, 0.012) | Unity 環境光。只影響內建 Lit 材質；StarrySky 的 Shader 用各自材質的「背光面最低亮度」 |
| Disable Directional Lights | 開 | 取消勾選，Directional Light 會重新打開（對 StarrySky 的 Shader 沒有影響） |

想看衛星的受光：點左側列表的 **Jupiter** 或 **Saturn** 放大，衛星亮的那一面會和母行星一樣朝向太陽。
從俯視看，太陽在畫面中心，所以每顆衛星都是「朝內側亮、朝外側暗」的半圓。

**想讓編輯模式（不按 Play）也是黑的**：選 Main Camera → Camera 元件的 **Environment > Background Type** 改成 *Solid Color*、顏色設黑；
**Window > Rendering > Lighting > Environment**，Skybox Material 設 None。再 **Ctrl + S** 存場景。

## 3. 原理

### 3.1 光的方向從哪來
`SunVisual` 每幀把太陽的世界座標寫進全域 Shader 變數 `_StarrySkySunPos`。每個 StarrySky Shader 都 `#include "PlanetLighting.cginc"`：

```hlsl
float3 L = StarrySkyLightDir(worldPos);   // = normalize(太陽位置 - 這個像素的位置)
```

這就是**點光源**：光從一個點往四面八方發射，每個位置看到的光方向都不同。
Directional Light 則是**平行光**：整個場景同一個方向，適合模擬「很遠的太陽照在地面上」，但不適合太陽在畫面中間的太陽系。

### 3.2 Lambert 漫反射
```hlsl
float lit = saturate(dot(N, L));          // N = 表面法線，L = 指向光源的方向
float3 col = _Color.rgb * (lit + _Ambient);
```

- 表面正對光源（N 和 L 同方向）時 `dot = 1`，最亮；斜著時變暗；背對時是負數，`saturate` 夾到 0。
- `_Ambient`（預設 0.02）讓背光面不是全黑，還看得到一點輪廓。
- 這和行星的 `Planet.shader` 是同一個公式（行星另外有凹凸、大氣等效果），所以衛星和行星的明暗一致。

### 3.3 為什麼不用 URP 的 Point Light
| | URP Point Light | 自訂（現在的作法） |
| --- | --- | --- |
| 衰減 | 1/d² 加上 Range 限制，海王星在 300 單位外，幾乎照不到 | 不衰減，所有天體一樣亮（之後可以加可調的衰減，見第 5 節） |
| Shader | 要用 URP 的 Lit Shader 或寫 URP 專用的光照程式 | 我們的 Shader 沒有 `LightMode` 標籤，本來就收不到 URP 的光 |
| 控制 | Unity 決定 | 公式全部自己寫，看得懂、改得動 |

### 3.4 背景與環境光
- **Clear Flags**：相機每一幀開始畫之前，先用什麼把畫面清掉。`Skybox` = 畫天空盒，`Solid Color` = 塗滿一個顏色。
- **環境光（Ambient）**：從四面八方來、沒有方向的光，Unity 預設從天空盒取樣。天空盒拿掉後改成 `Flat`（單一顏色），再調到接近黑。
- `DynamicGI.UpdateEnvironment()`：換掉天空盒後請 Unity 重算環境光。

觀念的完整介紹見 [Shader與URP入門教學.md](Shader與URP入門教學.md) 第 7 節。

## 4. 驗證

- C# 用 `dotnet build` 編譯通過（0 錯誤）。
- **SimpleBody Shader 尚未在 Unity 中確認**（Shader 只能在 Unity 裡編譯）。
- 確認方法：按 Play → 背景是黑的；Hierarchy 的 Directional Light 變成灰色（被關掉）；放大木星，四顆伽利略衛星的亮面都朝向太陽。

## 5. 已知限制與下一步

- 停止 Play 後，相機背景、天空盒、Directional Light 會恢復原狀（這些是執行時改的）。要永久改請照第 2 節手動設定。
- 光不隨距離衰減，海王星和水星一樣亮。下一步（第 3 層）：在 `PlanetLighting.cginc` 加「衰減程度」參數，0 = 不衰減、1 = 真實平方反比。
- 沒有天體之間的影子（月食、日食），只有土星環的影子。
- 星空：已加上，見 [星空說明.md](星空說明.md)。
