# 時間控制按鍵說明

按下 Play 後，畫面右上角會顯示播放速度與模擬時間，並可用鍵盤控制速度。
程式：`Assets/Script/N-body/TimeControlUI.cs`（掛在場景的 **Simulator** 物件上）。
畫面左側的天體列表與相機操作（滑鼠點選、滾輪、`Esc`）見 [相機與天體列表說明.md](相機與天體列表說明.md)。

> 按鍵只在 **Game 視窗有焦點**時有效。按了沒反應的話，先用滑鼠點一下 Game 視窗。

---

## 1. 按鍵一覽

| 按鍵 | 功能 |
| --- | --- |
| `+`（主鍵盤的 `=` 鍵，或數字鍵盤 `+`） | 加速：播放速度 ×2 |
| `-`（主鍵盤，或數字鍵盤 `-`） | 減速：播放速度 ÷2 |
| `1` | 預設速度 0.1 天/秒 |
| `2` | 預設速度 1 天/秒 |
| `3` | 預設速度 5 天/秒 |
| `4` | 預設速度 30 天/秒（場景預設值） |
| `5` | 預設速度 100 天/秒 |
| `6` | 預設速度 365 天/秒 |
| `空白鍵` | 暫停 / 繼續 |
| `H` | 顯示 / 隱藏按鍵說明 |

- 主鍵盤的 `+` 和 `=` 是同一顆鍵，不用按 Shift。
- 數字鍵是主鍵盤上排的 `1`~`6`，不是數字鍵盤。
- 播放速度限制在 0.01 ~ 1000 天/秒之間。

---

## 2. 畫面資訊

```
播放速度：30 天/秒
實際速度：29.9 天/秒
模擬時間：1 年 123.4 天
```

| 項目 | 說明 |
| --- | --- |
| 播放速度 | 設定值（`NBodySimulator.daysPerSecond`）：每 1 秒真實時間，希望推進幾天。暫停時旁邊會顯示「（暫停中）」。 |
| 實際速度 | 每 0.5 秒量一次，模擬實際推進了多少天。正常時應與播放速度接近。 |
| 模擬時間 | 從按 Play 開始，模擬已經經過多久（1 年 = 365.25 天）。 |

### 實際速度變紅：「算力跟不上」

當實際速度低於播放速度的 90% 時會變紅。原因是每幀需要的積分步數超過 `Max Steps Per Frame`（預設 2000），超出的時間會被捨棄。

每幀需要的步數 ≈ 播放速度 ÷ dt ÷ 每秒幀數。目前 dt = 0.001 天，在 60 fps 下：

| 播放速度 | 每幀步數 | 狀態 |
| --- | --- | --- |
| 30 天/秒 | 500 | 正常 |
| 100 天/秒 | 1667 | 接近上限，視電腦效能可能變紅 |
| 365 天/秒 | 6083 | 一定跟不上，實際約 120 天/秒 |

變紅時模擬**仍然正確**，只是比設定的慢。想要更快的話：

- 調高 Simulator 的 **Max Steps Per Frame**（會更吃 CPU，可能掉幀）。
- 在 `Planets.csv` 停用火衛一、火衛二，把 dt 放寬到 0.002，每幀步數減半。

## 3. 建議的速度

不同天體的公轉週期差很多（見 [Planets.csv欄位說明.md](Planets.csv欄位說明.md)），沒有一個速度能同時看清楚所有天體。經驗法則：**想看的天體大約 2 ~ 5 秒轉一圈**最舒服。

| 想看 | 建議速度 | 按鍵 |
| --- | --- | --- |
| 火衛一 Phobos（0.32 天） | 0.1 天/秒，約 3 秒一圈 | `1` |
| 木衛一 Io、土衛一 Mimas 等內側衛星 | 0.1 ~ 1 天/秒 | `1`、`2` |
| 木衛三、木衛四、土衛六、月球 | 5 天/秒 | `3` |
| 水星、金星、地球、火星 | 30 ~ 100 天/秒 | `4`、`5` |
| 木星以外的行星 | 365 天/秒以上 | `6`，再按 `+` |

軌跡長度會自動跟著播放速度調整（固定顯示 0.3 圈，見 [TrailRenderer教學.md](TrailRenderer教學.md)），所以切換速度後，軌跡會跟著變長或變短。

---

## 4. 暫停的運作方式

暫停是把 `Time.timeScale` 設為 0：

- `NBodySimulator` 用 `Time.deltaTime` 推進時間，timeScale = 0 時 deltaTime = 0，模擬就停了。
- TrailRenderer 也跟著停住，**軌跡不會在暫停時消失**。
- 暫停中仍可以按 `+`、`-`、數字鍵改速度，繼續後就用新速度播放。

停止 Play 或停用 TimeControlUI 元件時，會自動把 timeScale 還原成 1。

## 5. 自訂

在 Hierarchy 選 **Simulator** → Inspector 的 **Time Control UI**：

| 欄位 | 說明 |
| --- | --- |
| Presets | 數字鍵對應的速度，第 1 個對應 `1` 鍵，依此類推，最多 6 個。 |
| Min / Max Days Per Second | 播放速度的下限與上限。 |
| Show Help | 一開始是否顯示按鍵說明。 |
| Font Size | 字體大小。 |

要改按鍵本身，編輯 `TimeControlUI.cs` 的 `HandleKeys()`。專案使用新版 **Input System**（Project Settings → Player → Active Input Handling = Input System Package），所以按鍵寫法是 `Keyboard.current.xxxKey.wasPressedThisFrame`，舊版的 `Input.GetKeyDown()` 在這個專案中會報錯。
