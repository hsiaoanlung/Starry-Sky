# 自轉說明（CSV 的 rotationPeriod 欄）

最後更新：2026-10-27

`Planets.csv` 新增 `rotationPeriod` 欄（恆星自轉週期，單位：天），按下 Play 後每顆有填的天體會繞自己的自轉軸旋轉。
轉速跟著模擬時間走，暫停就停、慢放就慢；播放速度太快時有上限，避免轉到看不清。

| 項目 | 原本 | 現在 |
| --- | --- | --- |
| 怎麼轉 | 木星、土星等 5 顆在 Shader 裡把貼圖沿經度捲動（`_RotationSpeed`，UV / 真實秒） | 整個物件繞自轉軸旋轉（`BodySpin` 元件） |
| 速度從哪來 | 隨便給的數字，和真實比例無關 | CSV 的真實自轉週期（地球 0.997 天、木星 0.414 天…） |
| 和模擬的關係 | 沒關係，暫停也繼續轉 | 跟著模擬時間：暫停會停、改播放速度會變 |
| 哪些會轉 | 5 顆氣態 / 有大氣的行星 | 太陽 + 八大行星（衛星的欄位空白，不轉） |

## 2. CSV 怎麼填

```
name,...,prefab,rotationPeriod
Earth,...,Prefabs/Planets/Earth,0.99727
Venus,...,Prefabs/Planets/Venus,243.025
Moon,...,,                          ← 空白 = 不自轉
```

| 天體 | rotationPeriod（天） | 備註 |
| --- | --- | --- |
| 太陽 | 25.38 | 赤道附近的週期（太陽各緯度轉速不同） |
| 水星 | 58.646 | 剛好是公轉週期的 2/3 |
| 金星 | 243.025 | 比它的一年（224.7 天）還長；逆向自轉由 Prefab 的 177.4° 傾角表現 |
| 地球 | 0.99727 | 恆星日 23 時 56 分，不是 24 小時（見 3.1） |
| 火星 | 1.02596 | |
| 木星 | 0.41354 | 約 9.9 小時，八大行星中最快 |
| 土星 | 0.44401 | |
| 天王星 | 0.71833 | 傾角 97.8°，躺著轉 |
| 海王星 | 0.67125 | |

- 正數 = 從自轉軸的北極（物件的 local y）往下看**逆時針**，和公轉同方向。
- 負數 = 反方向。一般不需要：金星、天王星的「逆向」已經包含在 Prefab 的傾角裡（見 3.2），再填負數會轉回來。
- 0 或空白 = 不轉。

## 3. 原理

### 3.1 恆星日 vs 太陽日
地球「轉一圈」有兩種算法：

- **恆星日**（23 時 56 分 4 秒 = 0.99727 天）：相對遙遠的恆星轉 360°。
- **太陽日**（24 小時）：太陽再次回到天空同一個位置。地球同時在公轉，每天往前走了約 1°，所以要多轉約 4 分鐘太陽才會回到原位。

模擬裡 `BodySpin` 讓物件在**空間中**轉 360°，這就是恆星日。太陽日會自然地從「自轉 + 公轉」組合出來，不用另外算。
金星最誇張：自轉 243 天、公轉 224.7 天又是逆向自轉，算出來的太陽日約 117 天。

### 3.2 自轉軸 = 物件的 local y
Prefab 的根物件已經繞 z 軸傾斜（地球 0°、土星 26.7°、天王星 97.8°、金星 177.4°），傾斜後物件自己的 y 軸就是自轉軸。

```csharp
transform.Rotate(Vector3.up, degrees, Space.Self);   // Space.Self：繞「自己的」y 軸，不是世界的 y 軸
```

傾角超過 90° 代表自轉軸的北極朝下，從上方看就變成順時針，也就是**逆向自轉**。
天文上就是這樣定義的：金星的傾角是 177.4°，而不是「傾角 2.6° + 自轉週期為負」。兩種寫法描述的是同一件事。

### 3.3 Unity 是左手座標
Unity 的 `Rotate(Vector3.up, 正角度)` 從上方往下看是**順時針**（+z 轉向 +x）。
模擬的公轉從上方看是逆時針，所以程式用負號：

```csharp
float degrees = (float)(-360.0 * days / rotationPeriodDays);
```

### 3.4 用模擬時間，但有上限
```
這一幀的模擬天數  days = SimulatedDays(現在) − SimulatedDays(上一幀)
上限              days = min(days, maxSpinDaysPerSecond × Time.deltaTime)
這一幀轉的角度    = −360° × days / rotationPeriod
```

- 用 `NBodySimulator.SimulatedDays` 的差值，而不是 `daysPerSecond × deltaTime`：暫停時差值是 0，電腦算不動、模擬變慢時自轉也跟著變慢，永遠和公轉一致。
- 放在 `LateUpdate`：`NBodySimulator.Update` 先推進這一幀的模擬時間，自轉再跟上。

**為什麼要上限？** 預設播放 30 天/秒時，木星每秒要轉 72 圈，60 fps 下每幀轉 435°。
每幀轉的角度接近或超過 180° 時，眼睛分不出它往哪邊轉，看起來會亂閃或像倒轉（和影片裡車輪倒轉是同一個現象，叫 *aliasing*，或 *wagon-wheel effect*）。

上限是對「時間」設的，不是對「轉速」設的，所以所有天體一起變慢，**快慢比例和真實一樣**。預設上限 1 天/秒時（60 fps）：

| 天體 | 每秒 | 每幀 | 轉一圈 |
| --- | --- | --- | --- |
| 木星 | 871° | 14.5° | 0.41 秒 |
| 地球 | 361° | 6.0° | 1.0 秒 |
| 太陽 | 14° | 0.24° | 25 秒 |
| 金星 | 1.5° | 0.02° | 4 分鐘 |

播放速度在 1 天/秒以下時（例如按 `1` 設成 0.1 天/秒），上限不起作用，自轉完全照模擬時間。

## 4. 可調參數

### Simulator > SolarSystemBuilder > 自轉（Play 中可即時調）
| 參數 | 預設 | 說明 |
| --- | --- | --- |
| Add Spin | 開 | 關掉 = 全部停止自轉（停在目前的角度） |
| Max Spin Days Per Second | 1 | 越大轉得越快；0 = 不設上限 |

### 每顆天體的 BodySpin（Play 中選天體）
| 參數 | 說明 |
| --- | --- |
| Rotation Period Days | 從 CSV 讀來，Play 中可以改來試；停止 Play 後還原，要永久修改請改 CSV |

## 5. 已知限制與下一步

- **尚未在 Unity 中確認**：C# 編譯通過，但還沒按 Play 看過效果。
- 衛星沒有填：衛星目前是純色球，轉了也看不出來。之後做衛星 Prefab 時，大部分衛星是**潮汐鎖定**（自轉週期 = 公轉週期，例如月球 27.32 天，永遠同一面朝著母星），填公轉週期就好。
  注意潮汐鎖定靠的是「兩個週期剛好相等」，模擬時間有上限時自轉會變慢、公轉不會，會慢慢對不上；要真正鎖定得改成「每幀面向 parent」。
- 太陽表面和日冕的噪聲是用物件空間座標算的，所以會跟著太陽一起轉（約 25 秒一圈）。
- 真實的太陽和氣態行星是**較差自轉**（赤道轉得比兩極快），這裡整顆一起轉。木星、土星、海王星的雲帶相對流動（`_BandShear`）還在，可以補一點這種感覺。
- `_RotationSpeed` 這個 Shader 參數還留著（預設 0），想讓大氣比地表轉得快時可以再調（例如金星的大氣約 4 天就繞一圈）。
