# 行星 Prefab 說明（水星～海王星）

最後更新：2026-10-26

七顆行星的程序化貼圖與 Prefab。地球有自己的 Shader（雲、夜間燈光），見 [地球Prefab說明.md](地球Prefab說明.md)。
目前**只做成 Prefab 試看**，還沒接進 N-body 模擬；衛星還沒做。

基礎觀念見 [Shader與URP入門教學.md](Shader與URP入門教學.md)。

## 2. 每顆行星怎麼做的

### 2.1 岩石行星：顏色 + 高度

| 行星 | 做法 |
| --- | --- |
| **水星** | 灰色 fBm 底色 + 三種尺寸的隕石坑（12 個盆地、400 個中型、5000 個小坑）；少數新鮮的坑周圍比較亮，還有放射紋 |
| **金星** | 看不到地面，只有濃厚的黃白色雲層：東西向拉長的條紋，加上隨經度彎曲的 Y 形結構 |
| **火星** | 鏽紅底色 + 深色區域（噪聲）；南北二分（北半球低地）、塔爾西斯高原、奧林帕斯山、水手號峽谷、希臘盆地；隕石坑集中在南半球；南北極冠 |

**隕石坑**（`add_craters`）：
- 半徑符合「N(> r) ∝ r⁻²」的冪次分布：小坑很多、大坑很少，和真實的星球表面一樣。
- 剖面 = 碗狀凹陷 + 隆起的坑緣 + 大坑的中央峰。
- 只處理坑所在的那幾列像素，所以 5000 個坑也只要幾秒。

高度存在貼圖的 **A 通道**，Shader 用它做「凹凸」（見 3.2）。

### 2.2 氣態行星：雲帶

| 行星 | 做法 |
| --- | --- |
| **木星** | 依緯度查顏色表（亮的「帶 zone」與暗的「帶 belt」交錯），用噪聲擾動緯度做出亂流；大紅斑（南緯 22°）內部用旋轉座標取樣噪聲，看起來像在打轉；南溫帶幾個白色小橢圓 |
| **土星** | 同樣的做法，但對比低、亂流小；北極偏灰藍 |
| **天王星** | 幾乎沒有特徵的青綠色，極區稍亮，兩朵小亮雲 |
| **海王星** | 深藍雲帶 + 大黑斑與白色伴雲 + 高空白色條狀雲 |

`gas_bands()` 的核心：

```
擾動後的緯度 = 緯度 + 亂流強度 × fBm(南北方向頻率放大的座標)
顏色 = 顏色表(擾動後的緯度)
```

南北方向的頻率放大 6～8 倍，噪聲圖案就會被「壓扁」成東西向的長條，像被高速的緯向風吹過。

### 2.3 土星環

`SaturnRings.png` 是一張 2048 × 4 的**徑向剖面**：橫軸是離土星中心 1.1～2.4 倍土星半徑，RGB 是顏色，A 是不透明度。

| 環 | 半徑（土星半徑） | 不透明度 |
| --- | --- | --- |
| D 環 | 1.11 ～ 1.24 | 很淡 |
| C 環 | 1.24 ～ 1.53 | 半透明、偏暗 |
| B 環 | 1.53 ～ 1.95 | 最亮、幾乎不透明 |
| 卡西尼縫 | 1.95 ～ 2.03 | 幾乎空的 |
| A 環（含恩克縫 2.214～2.222） | 2.03 ～ 2.27 | 中等 |
| F 環 | 2.32 | 細細一條 |

再疊上兩種頻率的 1D 噪聲，做出很多細環紋。

## 3. Shader

### 3.1 光從太陽來
`PlanetLighting.cginc` 的 `StarrySkyLightDir()`：場景裡有太陽（`SunVisual`）時，光的方向 = 從這一點指向太陽；沒有太陽時用材質的「預覽用光線方向」。地球的 Shader 也是同樣的規則。

### 3.2 Planet.shader 的功能（全部用參數開關）

| 功能 | 參數 | 原理 |
| --- | --- | --- |
| 地形凹凸 | 地形凹凸強度 | 取左右、上下相鄰像素的高度差，把法線往下坡方向傾斜 → 隕石坑在晨昏線附近有明顯的陰影 |
| 自轉 | 自轉（UV / 秒） | 整張貼圖沿經度捲動 |
| 雲帶流動 | 雲帶相對流動 | 不同緯度捲動速度不同（用 sin(緯度) 調整），雲帶會互相滑動 |
| 臨邊昏暗 | 臨邊昏暗 | 顏色乘上 `pow(N·V, 值)`，氣態行星邊緣變暗 |
| 大氣邊緣光 | 大氣顏色 / 邊緣寬度 | 和地球一樣的 Fresnel，顏色設黑色 = 關 |
| 環的影子 | 環的影子 | 從表面往太陽發射一條線，算它和赤道面的交點離中心多遠，查環貼圖的不透明度 |

**凹凸的法線傾斜**：

```
N' = normalize( N − 強度 × (∂h/∂u · T + ∂h/∂v · B) )
```

`T`（切線）指向貼圖 u 增加的方向（東），`B`（副切線）指向 v 增加的方向（北）。
高度往東增加 → 表面朝西傾斜 → 法線減去一點 T。這是不用法線貼圖、直接從高度算凹凸的簡單做法。

### 3.3 PlanetRing.shader

- 環是一張 **Quad**，在 Prefab 裡繞 x 軸轉 90°、躺在土星的赤道面上，邊長 2.4（= 環外緣直徑；土星直徑 1）。
- `r = |uv − 0.5| × 2 × 外緣半徑`：把 UV 換算成離中心幾倍土星半徑，超出環的範圍就 `clip` 掉不畫。
- **土星的影子落在環上**：從環上的點往太陽發射一條線，看會不會打到土星球體（射線與球的交點公式）。
- 照到光的那一面亮；從背面看是透過環的散射光，比較暗（「背光面亮度」）。
- Alpha 混合（`Blend SrcAlpha OneMinusSrcAlpha`）：環的縫隙可以看到後面的土星與星空。

## 4. Prefab 的設定

| 行星 | 自轉軸傾角 | 自轉（UV/秒） | 其他 |
| --- | --- | --- | --- |
| 水星 | 0° | — | 凹凸 8 |
| 金星 | 177.4°（上下顛倒 → 看起來是逆向自轉） | 0.003 | 黃色大氣 |
| 火星 | 25.2° | — | 凹凸 5、淡紅大氣 |
| 木星 | 3.1° | 0.004 | 雲帶流動、臨邊昏暗 |
| 土星 | 26.7° | 0.0035 | 環 + 環的影子 |
| 天王星 | 97.8°（躺著自轉） | 0.002 | 臨邊昏暗 |
| 海王星 | 28.3° | 0.003 | 雲帶流動 |

- 傾角做在 Prefab 根物件的 Rotation（繞 z 軸），環是子物件所以會跟著傾斜。
- 所有行星直徑都是 1，大小之後接進模擬時再依 `displayRadius` 縮放。
- 自轉速度只是「看起來在轉」，沒有照真實比例（真實比例在高播放速度下會快到看不清）。

## 5. 已知限制與下一步

- 貼圖都是程序化產生的近似，不是真實地圖（可換 NASA / USGS 的公有領域貼圖，Shader 不用改）。
- 凹凸用 8-bit 高度，非常近看可能有階梯感；可以改輸出 16-bit 高度或法線貼圖。
- 天王星、海王星的環很暗，這次沒做。
- 下一步：讓 `SolarSystemBuilder` 依 CSV 的名字載入對應的 Prefab，取代現在的單色球；衛星。
