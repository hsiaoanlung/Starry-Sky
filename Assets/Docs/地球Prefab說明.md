# 地球 Prefab 說明

最後更新：2026-10-26

一顆有程序化貼圖的地球：白天地表、海面反光、會飄的雲、夜晚城市燈光、大氣藍色邊緣。
目前**只做成 Prefab 試看效果**，還沒有接到 N-body 模擬裡（模擬中的地球仍是 `SolarSystemBuilder` 產生的藍色球）。

基礎觀念（Shader 結構、噪聲、fBm、domain warping）見 [Shader與URP入門教學.md](Shader與URP入門教學.md)。

## 2. 怎麼看

**方法一：Prefab 模式**
在 Project 視窗雙擊 `Assets/Prefabs/Earth.prefab`。沒有太陽時，光線方向用材質上的「預覽用光線方向」。

**方法二：放進場景**
把 Prefab 拖進任何場景，選 `Earth` 材質就能調整參數。

> 雲會隨時間飄動。在 Scene 視窗要看到動畫，請打開 Scene 視窗上方的特效選單（像一張圖片的圖示）→ 勾 **Always Refresh**。

## 3. 貼圖怎麼產生的（earth_texture_gen.py）

```
python Assets/Docs/earth_texture_gen.py            # 2048 x 1024，種子 7（約 1 分鐘）
python Assets/Docs/earth_texture_gen.py 4096 11    # 寬度 4096、種子 11
```

換種子 = 換一組大陸形狀。重新產生後回到 Unity 會自動重新匯入。

### 3.1 等距長方投影（equirectangular）
貼圖寬:高 = 2:1，橫軸是經度（−180°～180°），縱軸是緯度（上 = 北極）。
Unity 內建球體的 UV 剛好是這種排法，所以貼圖可以直接貼上去。

### 3.2 為什麼在 3D 空間取樣噪聲
如果直接在 2D 貼圖上取樣噪聲，會有兩個問題：左右邊界（經度 ±180°）接不起來，兩極的圖案被拉成放射狀。
腳本先把每個像素換算成**球面上的點** `(x, y, z)`，再取樣 3D 噪聲。球面本身是連續的，所以沒有接縫、兩極也正常。

### 3.3 每一張貼圖

| 貼圖 | 做法 |
| --- | --- |
| **高度** | domain-warped fBm 做大陸形狀，高處再加 ridged noise 做山脈；取面積加權 70% 分位數當海平面 → 剛好 70% 是海 |
| **地表顏色** | 用「溫度」（緯度、海拔）和「濕度」（噪聲，副熱帶 25° 附近較乾）決定：森林、草原、沙漠、苔原、岩石、雪；緯度 68° 以上加極冠 |
| **海洋遮罩** | 海平面以下且不是海冰 → A = 255，Shader 只在這裡做反光 |
| **雲** | 把南北方向的頻率放大 2.5 倍，雲會沿東西向拉長（模擬緯向風）；赤道和中緯度雲多、副熱帶 25° 雲少 |
| **夜間燈光** | 只在可居住的陸地；溫和、濕潤、低海拔、靠海岸的地方人口多；再用高頻噪聲打散成光點 |

> **面積加權**：等距長方投影的高緯度像素代表的實際面積很小（乘 cos(緯度)），
> 算「70% 是海」「55% 有雲」時要加權，否則極區被算太多。

## 4. Shader 的光照（Earth.shader）

這支 Shader **自己算光照**，不用 Unity 的燈。光的方向：

- 場景裡有太陽（`SunVisual`）→ 太陽每幀把位置寫進全域變數 `_StarrySkySunPos`，**光從太陽照向地球**。
- 沒有太陽 → 用材質的 `_LightDir`。

這樣地球永遠是朝太陽的那一面亮，比 Directional Light 正確。

| 成分 | 計算 | 效果 |
| --- | --- | --- |
| 白天地表 | `albedo × max(N·L, 0)`（Lambert） | 朝太陽越亮 |
| 海面反光 | Blinn-Phong：`pow(N·H, 60) × 海洋遮罩` | 海上一個亮點，陸地和雲不反光 |
| 雲 | 雲貼圖的 u 隨時間平移；用雲量在地表與白色之間插值 | 雲會繞地球飄 |
| 雲的陰影 | 偏移一點再取樣一次雲，壓暗地表 | 雲下面有影子（簡化版） |
| 夜間燈光 | `燈光 × (1 − dayMask)` | 只出現在背光面，晨昏線附近漸變 |
| 大氣 | `pow(1 − N·V, 3)`（Fresnel）× 照光程度 | 邊緣一圈藍光 |

- `dayMask = smoothstep(-0.15, 0.2, N·L)`：晨昏線不是一刀切，而是一段漸層。
- 雲的 u 用 Repeat、v 用 Clamp（貼圖匯入設定），所以雲繞一圈會接回來，兩極不會接到另一邊。

### 4.1 可調參數（選 Earth 材質）

| 參數 | 說明 |
| --- | --- |
| 預覽用光線方向 | 沒有太陽時光從哪裡來 |
| 雲飄動速度 | 每秒移動多少 UV（0.004 ≈ 250 秒繞一圈） |
| 雲的陰影 | 0 = 沒有影子 |
| 夜間燈光亮度 | HDR，調高會被 Bloom 抓到 |
| 海面反光集中度 / 強度 | 集中度越大亮點越小 |
| 大氣顏色 / 邊緣寬度 | 寬度數字越大，藍邊越窄 |
| 背光面最低亮度 | 0 = 背光面全黑（只剩城市燈光） |

## 5. 已知限制與下一步

- 大陸是程序化產生的虛構地形，不是真實地圖。想要真實地球，可以換成 NASA *Blue Marble*（公有領域）的貼圖，Shader 不用改。
- 沒有法線貼圖，地形沒有立體凹凸。
- 地球沒有自轉；模擬播放速度很快時，自轉會快到看不清，需要另外設計。
- 大氣只是球體邊緣的 Fresnel 光，沒有延伸到球外。可以像日冕一樣加一層外殼。
- 下一步：讓 `SolarSystemBuilder` 在建立 Earth 時改用這個 Prefab。
