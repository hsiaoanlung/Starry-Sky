# Planets.csv 欄位說明

檔案位置：`Assets/Resources/Planets.csv`
讀取程式：`Assets/Script/N-body/PlanetSpec.cs`（解析）、`SolarSystemBuilder.cs`（建立天體）

可以用 Excel 直接開啟編輯，存檔後回 Unity 按 Play 即生效。

---

## 欄位一覽

| 欄位 | 單位 | 必填 | 影響 | 說明 |
| --- | --- | --- | --- | --- |
| `name` | — | 是 | 識別 | 天體名稱，也是 Hierarchy 裡的物件名稱。其他列的 `parent` 用這個名字找它，**不可重複**。 |
| `parent` | — | 否 | 初始條件、顯示 | 繞著哪顆天體轉。留空 = 放在原點靜止（例如太陽）。 |
| `mass` | 太陽質量 | 是 | **物理** | 太陽 = 1，地球 ≈ 3.00E-06。可寫科學記號。 |
| `a` | AU | 是 | 初始條件 | 相對 `parent` 的軌道半長軸。`parent` 留空時填 0。 |
| `e` | 無 | 是 | 初始條件 | 軌道離心率，0 = 正圓，必須 0 ≤ e < 1。 |
| `displayRadius` | Unity 單位 | 是 | 僅顯示 | 球的半徑，跟真實大小無關。 |
| `color` | `#RRGGBB` | 是 | 僅顯示 | 球與軌跡顏色。無法解析時改用白色。 |
| `orbitScale` | 倍數 | 否 | 僅顯示 | 顯示時把與 `parent` 的距離放大幾倍。留空 = 1。 |
| `retrograde` | 0 / 1 | 否 | 初始條件 | 1 = 逆行，繞 `parent` 的方向與其他天體相反（例如海衛一 Triton）。留空 = 0。 |
| `rotationPeriod` | 天 | 否 | 僅顯示 | 恆星自轉週期。正 = 繞自轉軸逆時針（和公轉同向），負 = 反向，留空 = 不自轉。見 [自轉說明.md](自轉說明.md)。 |
| `prefab` | 路徑 | 否 | 僅顯示 | 外觀用的 Prefab，路徑從 Resources 開始、不含 `.prefab`，例如 `Prefabs/Planets/Earth`。留空 = 純色球。見 [Prefab載入說明.md](Prefab載入說明.md)。 |

「影響」欄的意思：

- **物理**：每一步重力計算都會用到。
- **初始條件**：只在 t = 0 決定起始位置與速度，之後交給 N-body 自由演化。
- **僅顯示**：只改畫面，不影響任何計算結果。

## 欄位細節

### parent

- 所有天體在重力計算上**一律互相吸引**，`parent` 不會改變誰吸引誰。
- 它只決定兩件事：
  1. **起點**：天體放在 `parent` 的 +x 方向、距離為近日點 $r_p = a(1-e)$ 的位置，速度沿 +z，大小為
     $v_p = \sqrt{G (M_{parent} + m)(1+e) / r_p}$，再加上 `parent` 自己的速度。
  2. **顯示**：配合 `orbitScale`，畫面位置以 `parent` 為基準。
- 速度公式的推導見 [初始速度計算說明.md](初始速度計算說明.md)。
- **`parent` 必須在 CSV 中排在前面**（例如 Moon 要在 Earth 之後），否則該列會被略過並在 Console 報錯。

### mass

- 這是唯一直接影響重力計算的欄位。
- 常見換算：1 太陽質量 = 1.989 × 10³⁰ kg。例如月球 7.342 × 10²² kg ≈ 3.69E-08。

### a、e

- 所有天體都從近日點出發，所以初始時刻全部排在 +x 軸上（同一直線），這是正常的。
- 衛星的 `a` 是相對母星的距離，例如月球 0.00257 AU（約 38.4 萬公里）。

### orbitScale

- 用途：衛星離母星太近，在畫面上會被母星的球蓋住。例如月球真實距離換算後只有 0.026 Unity 單位，而地球半徑顯示為 0.15，所以月球設 25 倍。
- 行星與太陽保持 1。
- **同一顆行星的所有衛星請用同一個倍數**，衛星之間的遠近關係才會正確。目前設定：火星 300、地球 / 木星 / 海王星 25、土星 35、天王星 40。
- 只影響畫面。若衛星因數值誤差脫離母星，畫面仍會照「相對母星 × 倍數」畫，看起來會怪，這時請看 Console 的能量誤差 `dE/E`。

---

### retrograde

- 0（或留空）：從上方看逆時針公轉，與太陽系絕大多數天體相同。
- 1：初始速度方向反過來（沿 -z），順時針公轉。
- 目前只有海衛一 Triton 是逆行。它的真實軌道傾角約 157°，本模擬沒有軌道傾角，所以用「同平面、反方向」近似。

### prefab

- 只有 Resources 資料夾裡的 Prefab 讀得到：`Assets/Resources/Prefabs/Sun.prefab` → 填 `Prefabs/Sun`。
- 讀不到時 Console 會出現警告，那顆天體改用純色球，模擬照常進行。
- 目前太陽與八大行星有填；衛星留空。

### rotationPeriod

- 填**恆星自轉週期**（相對遙遠恆星轉一圈），單位是天。地球是 0.99727，不是 1。
- 金星、天王星的逆向 / 躺著自轉已經由 Prefab 的傾角表現，這裡照樣填正數。
- 播放速度很快時，自轉會被限制在每真實秒最多 1 天份（`SolarSystemBuilder > Max Spin Days Per Second`），比例不變。

## 規則與注意事項

- **第一列是標題**，程式會略過，但欄位順序必須照上表。
- **空白列**與 **`#` 開頭的列**會被略過，可用來暫時停用某顆天體（但若其他天體以它為 `parent`，那些也會被略過）。
- 分隔符號接受逗號 `,` 或分號 `;`。
- 數字一律用小數點 `.`，不要用千分位逗號。
- 用 Excel 存檔時選「保留 CSV 格式」，**不要存成 .xlsx**。
- `name` 建議用英文；若要用中文，存檔格式選「CSV UTF-8（逗號分隔）」以免亂碼。
- 某一列格式錯誤時，Console 會顯示是第幾列，該列略過，其他列照常載入。

## 新增衛星時的時間步長

衛星週期短，需要較小的 `dt`（Simulator 物件上的 NBodySimulator → Dt）。經驗法則：一圈至少要數百步（約 350～600 步）。

| 天體 | 週期 | 建議 dt（天） |
| --- | --- | --- |
| 水星 | 88 天 | ≤ 0.25 |
| 月球 | 27.3 天 | ≤ 0.05 |
| 木衛一 Io | 1.77 天 | ≤ 0.003 |
| 土衛一 Mimas | 0.94 天 | ≤ 0.002 |
| 火衛一 Phobos | 0.32 天 | ≤ 0.001 |

**dt 由週期最短的天體決定。** 目前表格中最快的是火衛一，所以場景設定為 `dt = 0.001`。
若把火衛一、火衛二用 `#` 停用，dt 可放寬到 0.002（由 Mimas 決定），計算量減半。

計算量 ≈ 每秒步數 × 天體配對數 = (daysPerSecond ÷ dt) × N(N−1)/2。
29 顆天體、每秒 30 天、dt = 0.001 時，每秒約 1200 萬次配對計算。若畫面卡頓，可以：

- 調低 Simulator 的 **Days Per Second**。
- 停用不需要的衛星。
- 注意 **Max Steps Per Frame**（預設 2000）：每幀需要的步數超過它時，模擬會變得比設定的速度慢，但不會出錯。
