# 衛星 Prefab 說明

把 20 顆衛星從「單色球」換成**各有特色的程序化表面**，並讓它們**潮汐鎖定**，永遠用同一面朝向行星，就像月球永遠用同一面對著地球。

| | 原本 | 現在 |
| --- | --- | --- |
| 外觀 | `SimpleBody`：單一顏色 + 光照 | `StarrySky/Planet`：程序化貼圖 + 地形凹凸（和行星同一個 Shader） |
| 自轉 | 不轉 | 潮汐鎖定（`TidalLock`）：每幀轉到「貼圖中央朝向行星」 |
| 形狀 | 全部是球 | 火衛一、火衛二是橢球（不規則的小天體） |
| CSV | prefab、rotationPeriod 欄空白 | prefab = `Prefabs/Moons/<名稱>`，rotationPeriod = `lock` |

---

## 1. 檔案

| 檔案 | 內容 |
| --- | --- |
| `Assets/Docs/moon_texture_gen.py` | 產生 20 張衛星貼圖 + 球形預覽圖（共用 `planet_texture_gen.py` 的撞擊坑函式） |
| `Assets/Textures/Moons/<名稱>Albedo.png` | RGB = 表面顏色、A = 高度。月球 2048 × 1024，其他 1024 × 512（共約 9 MB） |
| `Assets/Materials/Moons/<名稱>.mat` | `StarrySky/Planet` 材質（凹凸強度；泰坦有大氣邊緣光） |
| `Assets/Resources/Prefabs/Moons/<名稱>.prefab` | 直徑 1 的球；火衛一、火衛二是「根物件 + 子物件 Shape（非等比縮放）」 |
| `Assets/Script/N-body/TidalLock.cs` | 新元件：潮汐鎖定 |
| `PlanetSpec.cs` | rotationPeriod 欄可以填 `lock` |
| `SolarSystemBuilder.cs` | `lock` 的天體掛 `TidalLock`（不掛 `BodySpin`） |
| `Assets/Resources/Planets.csv` | 20 顆衛星填上 prefab 與 `lock` |

衛星在左側列表的文字顏色、軌跡顏色仍然用 CSV 的 `color` 欄。

---

## 2. 怎麼看

1. 按 Play，在左上列表點選衛星，例如 **Io**、**Iapetus**、**Enceladus**。
2. 按 `V` 切換視角。「迎光」可以看清楚表面，「背光」可以看到細細的亮邊。
3. 跟隨月球時，月海那一面會一直朝著地球；按 `4` 或 `5` 加速也不會跑掉。

**不開 Unity 預覽**：`python Assets/Docs/moon_texture_gen.py --preview`，打開 `Temp/StarrySkyPreview/moons_preview.png`。每顆衛星左邊是照 `Planet.shader` 公式畫的球（看向朝行星的那一面），右邊是貼圖。

## 4. 原理

### 4.1 貼圖的經度慣例

衛星不像行星那樣有「本初子午線要放在哪」的問題，但很多衛星**前後兩個半球長得不一樣**，所以要先約定方向：

| 貼圖經度 | 位置 | 例子 |
| --- | --- | --- |
| lon 0（貼圖正中央） | **朝向行星**的那一面 | 月海、Io 的貝利火山附近 |
| lon +90° | **前導面**：公轉前進的方向，迎面撞上太空塵埃 | 土衛八的黑色區域、土衛一的赫歇爾坑 |
| lon −90° | **後隨面** | 土衛四的亮紋、木衛二的混沌地形 |

### 4.1.1 Unity 球體的 UV 是「反著」的

第一次在 Unity 按 Play 時，20 顆衛星都出現 `TidalLock` 的警告：前導面和後隨面左右顛倒。

原因是 Unity 內建球體的 UV：**從北極往下看，u 是順時針增加**；一般地圖則是往東（逆時針，和自轉同向）增加。所以照一般地圖方向畫的貼圖，貼上去會左右鏡像（從外面看，東邊跑到左邊）。

修正方法：`moon_texture_gen.py` 存檔時把貼圖**左右翻轉**（u → 1 − u）。貼圖中央（u = 0.5）不動，所以朝向行星的那一面不變，只是 lon +90° 從貼圖的 3/4 處移到 1/4 處，剛好落在前導面。`TidalLock` 的檢查也改成找 u = 0.25。

| 存好的 PNG 位置 | 經度 |
| --- | --- |
| 1/4 處（u = 0.25） | lon +90°（前導面） |
| 正中央（u = 0.5） | lon 0（朝向行星） |
| 3/4 處（u = 0.75） | lon −90°（後隨面） |

> 這個發現也代表**行星的貼圖同樣是左右鏡像的**（地球的大陸、火星的奧林帕斯山位置東西相反）。因為都是程序化產生的，看不太出來；如果之後要換成真實的地圖（例如 NASA 的地球貼圖），要先左右翻轉。

### 4.2 潮汐鎖定

衛星的自轉被行星的潮汐力慢慢拖慢，最後**自轉週期 = 公轉週期**，永遠同一面朝向行星。這個專案的 20 顆衛星在真實世界都是這樣。

為什麼不在 CSV 填「自轉週期 = 公轉週期」，交給 `BodySpin` 處理？因為 `BodySpin` 有轉速上限（每秒最多 1 天份，避免畫面亂閃）。播放速度超過 1 天/秒時，自轉會變慢、公轉不會，兩者就慢慢對不上了。

所以 `TidalLock` 直接**每幀計算方向**：

```csharp
Vector3 toParent = parent.position - transform.position;   // 指向行星
toParent.y = 0;                                             // 軌道都在 XZ 平面
transform.rotation = Quaternion.LookRotation(toParent, Vector3.up) * meshToFace;
```

`meshToFace` 是「把貼圖中央（lon 0）轉到物件 +z 方向」的修正。它是在 `Start` 時從**網格的 UV**算出來的：找出 UV 最接近 (0.5, 0.5) 的頂點，那個頂點的方向就是 lon 0。這樣不需要事先知道 Unity 內建球體的 UV 是怎麼排的。

> 和真實的差別：真實的月球是「自轉速度固定、公轉速度在橢圓軌道上忽快忽慢」，所以從地球看月球會微微左右搖擺（**天秤動**，可以多看到約 59% 的表面）。`TidalLock` 每幀都精確朝向行星，所以沒有天秤動。

### 4.3 不規則形狀

半徑小於約 200 公里的天體，重力不夠把自己壓成圓球。火衛一（26 × 23 × 18 公里）、火衛二（15 × 12 × 11 公里）都是馬鈴薯形。

Prefab 的根物件要維持「直徑 1」，因為 `SolarSystemBuilder` 會把根物件等比例縮放成 CSV 的 `displayRadius`。所以把球放在子物件 **Shape** 上，對子物件做**非等比縮放**變成橢球（最長軸沿子物件的 x）。真實的火衛一是長軸指向火星；這裡長軸會不會剛好指向火星，要看 Unity 球體的 UV 中央在哪個方向，還沒在 Unity 中確認，不對的話把子物件 Shape 繞 y 轉 90° 就好。

### 4.4 共用的地形函式

`moon_texture_gen.py` 重用 `planet_texture_gen.py` 的 `add_craters`（冪次分布的撞擊坑：小坑多、大坑少），另外加了：

| 函式 | 用途 |
| --- | --- |
| `crater_at(lon, lat, r, depth)` | 指定位置的大坑（赫歇爾、奧德修斯、斯蒂克尼） |
| `rays(lon, lat, r, length)` | 新鮮撞擊坑的放射紋：沿方位角取噪聲 → 一條條亮線，越遠越淡 |
| `arc(normal, start, length, width)` | 大圓上的一段弧：峽谷、裂縫。到大圓的角距離 = `|asin(n · p)|` |
| `random_arcs(count, …, region)` | 一堆隨機的弧，可以限制在某個區域（例如後隨面） |
| `cratered(density, depth, fresh)` | 大、中、小三層坑一次打完 |

## 5. 可調參數

### 產生器 `moon_texture_gen.py`

每顆衛星是一個函式（`moon()`、`io()`、`iapetus()`……），顏色、坑的數量（`density`）、深度（`depth`）、新鮮坑比例（`fresh`）都寫在函式裡。檔案最後的 `MATERIAL` 表是凹凸強度；改了要重新執行一次建資產的腳本（或直接在 Unity 裡改材質）。

```
python Assets/Docs/moon_texture_gen.py Io Europa    # 只重新產生指定的衛星
```

### 材質（`Assets/Materials/Moons/`）

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| 地形凹凸強度 | 4（月球 8、Io 2、泰坦 0） | 2048 寬的貼圖，相鄰像素的高度差只有 1024 寬的一半，所以月球要加倍才會一樣凹凸 |
| 臨邊昏暗（泰坦） | 0.4 | 霧霾讓邊緣變暗 |
| 大氣顏色（泰坦） | (0.9, 0.5, 0.15) | 橘色的邊緣光，不超過 1，不會觸發 Bloom |

### 元件 `TidalLock`（Play 中選衛星）

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| Offset Degrees | 0 | 額外繞自轉軸轉幾度。0 = 貼圖中央正對行星 |

`SolarSystemBuilder > Add Spin` 關掉時，潮汐鎖定也會停止。

## 6. 已知限制與下一步

- 在 Unity 中按過 Play：29 顆天體載入、能量誤差約 10⁻¹²；`TidalLock` 的檢查發現 UV 鏡像，已用翻轉貼圖修正（見 4.1.1），**修正後還沒重新確認**。外觀還沒有回報。
- 沒有天秤動（見 4.2）。
- 衛星畫面上只有 0.02 ~ 0.08 單位大，要跟隨後拉近才看得到細節。
- 天王星的衛星在真實世界是繞著「躺著的」天王星赤道轉的，但這個模擬的軌道都在同一個平面上。
