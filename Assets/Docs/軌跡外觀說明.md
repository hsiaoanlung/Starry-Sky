# 軌跡外觀說明

把軌跡從「跟著星球大小的實心帶子」改成**固定像素寬度的發光細線**，而且可以用 `T` 鍵切換要顯示哪些軌跡，觀察行星時不會再被線擋住。

| | 原本 | 現在 |
| --- | --- | --- |
| 寬度 | 世界單位，`星球半徑 × 0.5`：跟隨地球時約 32 像素、木星約 25 像素 | 固定約 1.5 像素，拉近、拉遠都一樣細 |
| 混合 | `Sprites/Default` 一般半透明：線在行星前面時會把行星蓋掉 | **加法混合**：線只會讓畫面變亮，不會擋住後面的東西 |
| 頭端 | 全不透明，緊貼在星球後面 | 星球後面先空一小段，再慢慢變亮 |
| 數量 | 28 條全部顯示，衛星的線在行星周圍擠成一團 | 預設只顯示八大行星 + **目前跟隨的系統**的衛星；`T` 鍵切換 |
| 打包 | `Shader.Find("Sprites/Default")` 打包後可能找不到 | 材質放在 `Resources/Materials/Trail.mat`，一定會被打包 |

### 顯示模式

| 模式 | 顯示哪些軌跡 | 適合 |
| --- | --- | --- |
| 全部 | 所有天體（原本的樣子） | 看整個太陽系的熱鬧 |
| **行星 + 目前系統**（預設） | 八大行星；跟隨某顆行星時，再加上它的衛星 | 平常使用 |
| 只有目前系統 | 只有跟隨中的天體和它的衛星 | 專心看一顆行星的衛星怎麼繞 |
| 關閉 | 都不顯示 | 截圖、看星球本身 |

「目前系統」的範圍：

| 跟隨中 | 系統中心 | 顯示 |
| --- | --- | --- |
| 沒有（初始視角）或太陽 | 太陽 | 八大行星 |
| 行星，例如木星 | 木星 | 木星 + 木衛一～四 |
| 衛星，例如木衛一 | 它的母行星（木星） | 木星 + 木衛一～四（看得到兄弟衛星） |

## 3. 原理

### 3.1 固定像素寬度

TrailRenderer 的寬度是**世界單位**。透視相機下，同樣寬的東西離相機越遠，在螢幕上越細。所以相機靠近地球時，0.075 單位寬的線會變得非常粗。

反過來算：要讓線在螢幕上是 $p$ 個像素寬，世界寬度應該是多少？

透視相機在距離 $d$ 的地方，畫面高度（世界單位）是：

$$\text{畫面高度} = 2\,d\,\tan\frac{\text{FOV}}{2}$$

這段高度被分成 `Screen.height` 個像素，所以 1 像素 = $\dfrac{2\,d\,\tan(\text{FOV}/2)}{\text{Screen.height}}$ 世界單位，線的寬度就是：

$$\text{widthMultiplier} = p \times \frac{2\,d\,\tan(\text{FOV}/2)}{\text{Screen.height}}$$

程式裡的 $d$ 是星球**沿相機視線方向的深度**（`Dot(星球 − 相機, 相機前方)`），因為透視投影的縮小比例由深度決定，不是直線距離。

```csharp
float pixelAtUnitDistance = 2f * Mathf.Tan(cam.fieldOfView * 0.5f * Mathf.Deg2Rad) / Screen.height;
float depth = Vector3.Dot(trail.transform.position - cam.transform.position, cam.transform.forward);
trail.widthMultiplier = widthPixels * pixelAtUnitDistance * depth;
```

`TrailVisual` 加了 `[DefaultExecutionOrder(100)]`，讓它的 `LateUpdate` 在 `CameraFocus` 移動相機**之後**才執行，寬度才不會慢一幀。

> **限制**：整條線用同一個寬度（用星球所在的深度算）。軌跡很長、又從側面看時，離相機近的那一段還是會粗一點，遠的那一段細一點。

### 3.2 加法混合：線不擋住行星

原本的 `Sprites/Default` 是 Alpha 混合：

$$\text{結果} = \text{線} \times \alpha + \text{背景} \times (1 - \alpha)$$

$\alpha = 1$ 的地方完全看不到背景，線經過行星前面時就把行星蓋掉了。

新的 Shader 用 `Blend One One`（加法）：

$$\text{結果} = \text{線} + \text{背景}$$

背景永遠保留，線只是讓它變亮一點，在黑色太空上看起來像淡淡的光痕。另外 `ZWrite Off`（不寫深度）：線彼此不會互相遮擋；`ZTest` 照常，所以線跑到行星**後面**時仍會被行星擋住，前後關係正確。

混合模式的完整說明見 [Shader與URP入門教學.md](Shader與URP入門教學.md) 6.5 節。

### 3.3 用頂點顏色的 alpha 傳「在軌跡上的位置」

Shader 需要知道每個像素是在軌跡的頭（星球旁邊）還是尾巴，才能做淡入淡出。加法混合下 alpha 沒有用處，所以拿它來傳資料：

- `TrailVisual` 把 TrailRenderer 的 `colorGradient` 設成：顏色 = 天體顏色，**alpha 從頭 1 到尾 0**。
- TrailRenderer 會把漸層內插到每個頂點，Shader 收到的 `i.color.a` 就是「離頭多遠」。

```hlsl
float t = 1 - i.color.a;                              // 0 = 頭，1 = 尾
float head = smoothstep(0, _HeadFade, t);              // 頭端：從 0 慢慢變亮
float tail = pow(saturate(1 - t), _TailPower);         // 尾端：越舊越暗
return float4(i.color.rgb * head * tail * _Intensity, 0);
```

```
亮度
 1 ┤  ╭─╮
   │ ╱    ╲___
   │╱          ╲____
 0 ┼─────────────────────
   頭  ↑            尾
     headFade
```

### 3.4 切換顯示模式不會拉出直線

TrailRenderer 被停用（`enabled = false`）時不會記錄位置，重新啟用時會從舊位置直接連一條直線到新位置（見 [TrailRenderer教學.md](TrailRenderer教學.md) 第 4 節）。

所以隱藏時用的是 `forceRenderingOff = true`：**只是不畫**，元件仍在記錄位置，重新顯示時軌跡是完整的。淡入淡出則是把顏色乘上 0～1 的可見度（加法混合下乘 0 = 看不見）。

### 3.5 Bloom

加法混合的線疊在一起會越加越亮，超過 Bloom Threshold（1）就會發光。所以預設亮度 0.5：最亮的線顏色（木衛一 `#F0E050`，R = 0.94）× 0.5 ≈ 0.47，就算兩條線完全疊在一起也不到 1。

## 4. 可調參數

Play 中選 **Simulator**，在 Inspector 的 **Trail Visual** 調整，**立刻生效**。
`TrailVisual` 是 Play 時才掛上去的，**停止 Play 後數值會還原**；調到滿意的數值請告訴 Claude，再寫回程式的預設值。

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| Mode | 行星 + 目前系統 | 顯示模式，也可以按 `T` 切換 |
| Fade Time | 0.4 | 切換模式時淡入淡出的秒數 |
| Show Button | 開 | 右下角的切換按鈕 |
| Width Pixels | 1.5 | 頭端寬度（螢幕像素） |
| Tail Width | 0.4 | 尾端寬度 = 頭端的幾倍；0 = 收成尖點 |
| Intensity | 0.5 | 亮度。調太高，重疊的地方會觸發 Bloom |
| Head Fade | 0.04 | 頭端淡入長度（佔整條軌跡的比例）。越大，星球正後方空出越多 |
| Tail Power | 1.5 | 尾端淡出曲線。越大尾巴消失得越快；1 = 線性 |

軌跡**長度**還是在 **Solar System Builder > Trail Orbit Fraction**（預設 0.3 圈）。

## 5. 已知限制與下一步

- **尚未在 Unity 中確認**：Shader 只能在 Unity 裡編譯；C# 已用 `dotnet build` 編譯通過。
- 線很細（1.5 像素）時，如果 URP 沒開抗鋸齒（MSAA），移動中可能會有一點閃爍；可以把 Width Pixels 調到 2。
- 整條線用同一個寬度（第 3.1 節）；側視時近的那一段會比較粗。
- 線性色彩空間下，頂點顏色的 RGB 可能會被轉換，線的顏色和列表上的圓點可能有一點差異（alpha 不受影響，所以淡出不會錯）。
- 右下角按鈕和畫面點選共用滑鼠左鍵：如果按鈕剛好蓋在某顆星球上，點按鈕時可能也會選到那顆星球。

下一步可以考慮：

| 想法 | 說明 |
| --- | --- |
| 完整的軌道橢圓 | 用 LineRenderer 畫整圈淡淡的軌道，TrailRenderer 只畫亮的尾巴（待辦裡已有） |
| 跟隨時調暗其他軌跡 | 「全部」模式下，不在目前系統的軌跡亮度降低，而不是直接隱藏 |
| 真正的逐像素寬度 | 自己用 Mesh 產生線，在 Vertex Shader 裡依每個頂點的深度展開寬度，側視時也一樣粗 |
