# 視角切換說明

最後更新：2026-10-27

在左上的天體列表選了天體之後，畫面**左下角**會出現「視角」面板，可以從不同角度看那顆星，或站在它上面往外看。
程式：`Assets/Script/N-body/CameraFocus.cs`（和天體列表是同一個元件）。

| 項目 | 原本 | 現在 |
| --- | --- | --- |
| 角度 | 只有正上方往下看 | 6 種預設視角 + 右鍵拖曳自由轉 |
| 相機模型 | 「目標正上方 + 高度」 | **軌道相機**：目標 + 距離 + 俯仰角 + 方位角 |
| 切換時 | 只有位置會平滑移動 | 位置和方向都平滑過渡（`Lerp` + `Slerp`） |
| 滾輪 | 調高度 | 調距離；「從星球看出去」時改成望遠鏡（視野角度） |

---

## 1. 操作

| 操作 | 功能 |
| --- | --- |
| 左下角按鈕 | 切換視角 |
| 再按一次目前的視角 | 把右鍵拖曳的角度重設 |
| `V` | 切到下一個視角 |
| 右鍵拖曳 | 軌道視角：繞著星球轉；從星球看出去：轉頭 |
| 滾輪 | 軌道視角：拉近 / 拉遠；從星球看出去：望遠鏡倍率 |
| `Esc` | 回到初始視角（太陽系中心正上方），視角面板消失 |

- 切換到別的天體時，**視角會保留**（例如在「從星球看出去」時點木星，就會跳到木星上往外看）。
- 選太陽時，「迎光」「背光」是灰色：這兩個視角要知道太陽在哪個方向，太陽自己沒有。

---

## 2. 六種視角

| 視角 | 俯仰角 | 方位角 | 相機在哪 | 適合看 |
| --- | --- | --- | --- | --- |
| 俯視 | 90° | 0 | 正上方 | 衛星的軌道排列（和原本一樣） |
| 斜視 | 35° | 0 | 斜上方，從 −z 往 +z 看 | 立體感、土星環的傾斜 |
| 側視（軌道面） | 3° | 0 | 幾乎在軌道面上 | 自轉軸傾角（天王星躺著轉）、軌跡變成一條線 |
| 迎光（太陽在身後） | 10° | 跟著陽光的方向 | 太陽和星球之間 | 整顆被照亮的一面，像滿月 |
| 背光（看向太陽） | 5° | 朝向太陽 | 星球背後 | 黑色剪影 + 亮邊，後面是太陽和日冕；地球會剛好擋住太陽，像日食 |
| 從星球看出去 | 8°（稍微往下） | 朝向太陽 | 星球上方 1.15 倍半徑 | 從那顆星看到的天空：太陽、其他行星、衛星 |

「迎光」「背光」「從星球看出去」的方位角**每幀跟著太陽的方向重算**，星球公轉時相機也會跟著轉。

---

## 3. 原理

### 3.1 用兩個角度描述方向
相機的方向用 Unity 的 `Quaternion.Euler(pitch, yaw, 0)`：

- **yaw（方位角）**：繞世界的 y 軸左右轉。yaw = 0 朝 +z，yaw = 90° 朝 +x。
- **pitch（俯仰角）**：再繞自己的 x 軸上下轉。**正數 = 往下看**，90° = 正下方。

展開來，相機的前方向量是

```
forward = (sin yaw · cos pitch,  −sin pitch,  cos yaw · cos pitch)
```

這其實就是**球座標**：用「緯度 + 經度」描述球面上的一個點。

### 3.2 從方向反推方位角：atan2
「迎光」要讓相機朝陽光的方向看，所以要從向量算出角度：

```csharp
static float YawOf(Vector3 v) => Mathf.Atan2(v.x, v.z) * Mathf.Rad2Deg;
```

`atan2(x, z)` 和 `atan(x / z)` 不一樣：它看 x、z 的正負號判斷象限，所以 360° 都算得對，z = 0 時也不會除以 0。

### 3.3 軌道相機
```csharp
position = focus - rotation * Vector3.forward * distance;
```

從目標往「視線的反方向」退 `distance`，相機就會正好看著目標。
改 pitch / yaw 時，相機在一顆以目標為中心、半徑 distance 的球面上移動，這就是「繞著轉」。

「從星球看出去」則反過來：相機的**位置**固定在星球上方，只改方向，所以是「轉頭」。

### 3.4 平滑過渡：Lerp 與 Slerp
| | 用在 | 做法 |
| --- | --- | --- |
| `Vector3.Lerp(a, b, t)` | 位置 | 直線上的內插：`a + (b − a) × t` |
| `Quaternion.Slerp(a, b, t)` | 方向 | 沿球面的最短路徑轉，轉速均勻 |
| `Mathf.SmoothStep(0, 1, t)` | 時間曲線 | 開始和結束時慢、中間快，不會突然啟動或煞停 |

方向不能直接拿 Euler 角度做 Lerp：例如從 yaw 350° 轉到 10°，Lerp 會繞一大圈 340°，Slerp 只轉 20°。

### 3.5 滾輪縮放用指數平滑
```csharp
currentDistance = Mathf.Lerp(currentDistance, target, 1 - Mathf.Exp(-8 * dt));
```

每幀往目標靠近一個比例，而不是固定距離。`1 − e^(−8·dt)` 讓結果和幀率無關：60 fps 和 144 fps 看起來一樣快。

### 3.6 望遠鏡：改視野角度
「從星球看出去」時，滾輪改的是 `Camera.fieldOfView`（預設 60°，可調到 1°）。
視野越小，同樣大小的畫面只裝得下更小的一塊天空，看起來就被放大了，這就是望遠鏡的原理。
例如在地球上把視野縮到 2°，就看得清楚木星和它的衛星。

### 3.7 Near clip 要跟著改
「從星球看出去」時相機離表面只有 0.15 倍半徑，near clip 設成這段距離的 1/10，星球才不會被切掉。
在 0.15 倍半徑的高度、往下 8° 看時，地平線比水平低約 29.6°，畫面下緣（往下 30° + 8°）會看到約 8° 的星球表面。

## 4. 可調參數（Simulator > Camera Focus > 視角）

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| Oblique Pitch | 35 | 斜視的俯仰角 |
| Side Pitch | 3 | 側視的俯仰角；0 = 完全在軌道面上，軌跡會變成看不見的一條線 |
| Sun Lit Pitch | 10 | 迎光的俯仰角 |
| Backlit Pitch | 5 | 背光的俯仰角；0 = 太陽、星球、相機排成一直線 |
| Surface Height | 1.15 | 從星球看出去：離星球中心幾倍半徑；越接近 1，畫面下方的星球越大 |
| Surface Pitch | 8 | 從星球看出去：預設往下看幾度 |
| Drag Sensitivity | 0.2 | 右鍵拖曳每像素轉幾度 |
| Transition Time | 0.8 | 切換目標或視角的過渡時間（秒） |

Camera Focus 是場景裡的元件，在 **Play 之外**改的值會存進場景；Play 中改的值停止後還原。

## 5. 搭配建議

| 想看 | 怎麼做 |
| --- | --- |
| 土星環的立體感 | 選 Saturn → 斜視，右鍵往左右拖 |
| 天王星躺著轉 | 選 Uranus → 側視，按 `1` 放慢 |
| 「日食」 | 選 Earth → 背光；按 `1` 放慢，看太陽被擋住、只露出日冕 |
| 從地球看月亮的盈虧 | 選 Earth → 從星球看出去 → 右鍵拖曳找到月球 → 滾輪拉近 |
| 衛星的弦月 | 選 Jupiter → 迎光（全亮）和背光（細細的亮邊）比較 |

## 6. 已知限制

- 「從星球看出去」的相機放在星球的**世界上方**（+y），不是固定在地表某一點，所以不會跟著自轉（看不到日出日落）。
- 跟隨衛星或很快的行星時，「從星球看出去」的畫面背景移動很快，建議先放慢播放速度。
- 「背光」時太陽很亮，Bloom 會讓星球的剪影邊緣有一圈光暈，這是正常的。
- 側視時其他行星的軌跡幾乎是一條線，看不太出軌道形狀，這是同平面軌道的特性。
- UI 是 IMGUI（`OnGUI`）畫的，適合開發與展示。
