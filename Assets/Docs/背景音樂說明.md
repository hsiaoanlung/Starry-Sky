# 背景音樂說明

替星空場景加上**用數學合成的太空氛圍音樂**：低沉的持續音、慢慢變換的和弦，加上偶爾冒出的星星鐘聲。整段 96 秒，頭尾無縫，可以一直循環播放。音樂完全由 Python 程式產生，沒有用到任何錄音或素材，所以沒有版權問題；改參數就能重新產生一首。

| | 原本 | 現在 |
| --- | --- | --- |
| 聲音 | 完全無聲 | 循環播放 `SpaceAmbience.wav`，開始時 4 秒淡入 |
| 操作 | — | `M` 鍵靜音 / 取消靜音（淡入淡出，暫停中也能切換） |
| 來源 | — | `space_music_gen.py` 合成；改參數重新執行就換一首 |

原理（正弦波、泛音、包絡線、拍頻、殘響）見 [聲音合成入門教學.md](聲音合成入門教學.md)。

| 操作 | 功能 |

## 3. 原理：音樂是怎麼「算」出來的

整段音樂由三層聲音疊起來，最後再加上殘響：

| 層 | 做法 | 聽起來 |
| --- | --- | --- |
| 1. 持續音（drone） | D2（73.4 Hz）和 73.5 Hz 兩個正弦波，加上高八度、五度和 D1 | 低沉的嗡鳴，每 8 秒左右緩慢起伏一次（拍頻） |
| 2. 和弦（pad） | Dm(add9) → B♭maj9 → Fmaj7 → C(add9)，每個和弦 24 秒，前後交疊 9 秒 | 遼闊、慢慢流動的背景 |
| 3. 星星（stars） | 平均每 2.8 秒一個隨機高音鐘聲（D 小調五聲音階），96 秒內共 38 個 | 像星星閃一下 |
| 風聲 | 兩個頻帶的噪聲，用慢速的 LFO 交替變大變小 | 很輕的「呼——」，填滿空隙 |
| 殘響 | 長度 7 秒的人工空間回聲 | 讓所有聲音有「很大的空間」的感覺 |

### 3.1 和弦為什麼選這四個

D 小調的 **i – VI – III – VII**（Dm → B♭ → F → C）是電影配樂、太空紀錄片很常用的進行：不像大調那麼明亮，也不像純小調那麼悲傷，而是開闊、帶一點神秘感。每個和弦再加上 9 度或 7 度音（add9、maj7），讓和聲比較柔和、沒有明確的「結束感」，適合無限循環。

星星的鐘聲只用 **五聲音階**（D F G A C）。五聲音階裡沒有半音，不管和哪個和弦同時響都不會刺耳，所以可以完全隨機挑音，不必配合和弦。

### 3.2 無縫循環

循環音樂最怕接縫處「喀」一聲：結尾的波形和開頭接不起來，或者結尾的回聲突然被切掉。這裡用三個方法，把整段音樂當成一個**環**來做：

1. **折回**：一個音如果超過結尾（例如最後一個和弦的淡出），超過的部分就加回開頭。
2. **整數圈**：一直在響的持續音和 LFO，頻率都取成 `k / 96 秒`（k 是整數），在 96 秒內剛好轉整數圈，結尾的相位剛好等於開頭。
3. **循環摺積**：殘響用 FFT 計算。FFT 本身就把訊號當成週期性的，結尾的回聲會自然繞回開頭。

檢查方法：比較「接縫處相鄰兩個取樣的跳動」和「整段的跳動」。實際數字是接縫 0.0045、整段中位數 0.0053，表示接縫和其他地方一樣平順；接縫附近 10 kHz 以上的能量也和平均值相同（喀聲會讓高頻能量突然變大）。

### 3.3 音量

| 項目 | 數值 | 說明 |
| --- | --- | --- |
| 峰值 | -3.1 dBFS | 最大的取樣是滿格的 70%，保留空間給 Vorbis 壓縮，避免爆音 |
| 平均響度 | -17.6 dBFS（RMS） | 背景音樂常見的範圍 |
| 每 4 秒響度 | -16 ~ -23 dB | 和弦交替時會自然起伏，但不會忽大忽小 |
| Unity 中的音量 | `volume` 0.2 | 再壓低，當背景不搶戲（2026-11-01 從 0.35 調小） |

`SpaceAudio` 的實際音量是 `volume × fade²`。人耳對音量的感覺接近對數，用平方的淡入曲線，聽起來會比線性淡入更平均。

## 4. 可調參數

### Unity：`SpaceAudio`（Play 中選 Simulator 即時調）

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| Clip | 空 | 留空 = 讀 `Resources/Audio/SpaceAmbience`。可以拖別的音檔進來 |
| Volume | 0.2 | 0 = 無聲，1 = 原始音量 |
| Muted | 關 | 靜音（等同 `M` 鍵） |
| Fade In Seconds | 4 | 開始播放時的淡入秒數 |
| Mute Fade Seconds | 0.6 | 靜音切換時的淡入淡出秒數 |

> 這個元件是執行時才掛上去的，**停止 Play 後數值會還原**。調到喜歡的數值後請告訴我，我會改成預設值。

### Python：`space_music_gen.py` 最前面

改完執行 `python Assets/Docs/space_music_gen.py` 就會覆寫 WAV，回到 Unity 會自動重新匯入。

| 參數 | 預設 | 越大會怎樣 |
| --- | --- | --- |
| `SEED` | 20261101 | 換數字 = 星星的時間和音高、聲部的相位全部重新隨機 |
| `CHORD_SECONDS` | 24 | 每個和弦越長、越平靜（整段長度 = 24 × 4 = 96 秒） |
| `CROSSFADE` | 9 | 和弦交疊越久、轉換越模糊 |
| `CHORDS` | 4 個和弦 | 用 MIDI 音號（60 = 中央 C）寫，可以改成自己的和弦 |
| `DRONE_BEAT_HZ` | 0.12 | 持續音起伏越快（0.12 Hz ≈ 每 8 秒一次） |
| `PAD_HARMONICS` | 8 | 泛音越多，和弦越亮、越像弦樂 |
| `PAD_BRIGHTNESS` | 1.7 | 高泛音越弱，聲音越暗、越柔 |
| `PAD_DETUNE_CENTS` | 7 | 三個聲部互相走音越多，聲音越寬、越飄（太大會像走音） |
| `STAR_INTERVAL` | 2.8 | 星星越稀疏 |
| `STAR_DECAY` | 1.2 ~ 3 秒 | 鐘聲餘音越長 |
| `REVERB_SECONDS` | 7 | 空間越大、回聲越長 |
| `REVERB_DAMP` | 0.35 | 回聲的高頻消失越快，聲音越暗 |
| `LEVEL_*` | 0.22 / 0.22 / 0.10 / 0.035 | 持續音 / 和弦 / 星星 / 風聲各自的音量 |
| `WET_PAD`、`WET_STARS` | 0.55 / 0.85 | 送進殘響的比例越高，聲音越遠、越朦朧 |
| `PEAK` | 0.70 | 最後的峰值（1 = 爆音邊緣） |

產生器也會輸出預覽圖 `Temp/StarrySkyPreview/space_music_preview.png`：上半是波形，下半是頻譜圖（橫軸時間、縱軸頻率，越亮越大聲）。紅線右邊是「循環回到開頭」的 6 秒，用來看接縫。

## 5. 已知限制與下一步

- **Claude 聽不到聲音**：只能用數字和頻譜圖檢查（有沒有爆音、接縫有沒有喀聲），好不好聽要使用者判斷。
- WAV 有 12.3 MB，會進 git。Unity 匯入時會壓成 Vorbis（約 1 ~ 2 MB），所以打包後不會變大。
- Unity 的 Vorbis 循環一般是無縫的；如果在 Unity 裡聽到接縫有一點停頓，可以把 meta 的 Compression Format 改成 PCM 試試看（記憶體會比較大）。
- 筆電喇叭幾乎放不出 D1（36.7 Hz）和 D2 的低音，用耳機聽會比較完整。
- 匯入設定（`.meta`）是手寫的，Unity 第一次匯入時可能會自動補上欄位，這是正常的。

**第 4 層：行星之歌**已完成，見 [行星之歌說明.md](行星之歌說明.md)：每顆行星一個音，音高由繞太陽的角速度即時決定。
