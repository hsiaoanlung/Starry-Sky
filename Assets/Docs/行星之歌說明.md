# 行星之歌說明

讓**八大行星各自發出一個音**，音高由它「現在」繞太陽的角速度決定，在 Unity 裡即時合成。這是把物理變成聲音（**數據音樂化**，sonification）：行星越靠近太陽、走得越快，音就越高；同一顆行星在近日點時音高會往上飄，到遠日點又降下來。

| | 背景音樂（`SpaceAudio`） | 行星之歌（`PlanetSong`） |
| --- | --- | --- |
| 來源 | 事先用 Python 合成好的 WAV | Unity 執行時**每 20 毫秒即時計算** |
| 跟模擬的關係 | 無關，一直循環 | 音高 = 物理狀態；音量、左右 = 相機位置 |
| 開關 | `M` | `P` |

同時把**預設播放速度改成 1 天/秒**（數字鍵 `2`，原本是 30 天/秒）：地球約 6 分鐘繞太陽一圈，比較看得清楚，也聽得出音高慢慢起伏。

| 檔案 | 內容 |

| `Assets/Script/N-body/PlanetSong.cs` | 新元件：每幀由位置、速度算音高；在音訊執行緒（`OnAudioFilterRead`）即時合成 |

| `SolarSystemBuilder.cs` | 新增「聲音 > Planet Song」開關；建立子物件 **Planet Song** 並掛上 `PlanetSong` |
| `TimeControlUI.cs` | 按鍵說明加上 `P` |
| `NBodySimulator.cs`、`N-body.unity` | 預設 `daysPerSecond` 30 → 1 |

`PlanetSong` 放在子物件上，因為 `OnAudioFilterRead` 會套用到**同一個物件上的 AudioSource**，如果和背景音樂放在同一個物件上，就會互相干擾。

## 2. 怎麼聽、怎麼操作

| 操作 | 會聽到 |
| --- | --- |
| 按 Play（俯瞰全景） | 八個音疊成一個和聲；離相機近的內行星比較清楚 |
| 點選一顆行星 | 相機飛過去，那顆行星的音變成主角，其他行星退成背景 |
| 點選衛星 | 聽到的是它的行星（衛星不發聲） |
| 跟隨水星，按 `4`（30 天/秒） | 每 3 秒一圈：音高在一個八度多的範圍內大幅起伏，近日點最高 |
| 跟隨地球，按 `5`（100 天/秒） | 每 3.7 秒一圈，音高在 D5 上下半音內擺動，就是克卜勒說的「mi–fa」 |
| 右鍵拖曳轉視角 | 行星在畫面左邊，聲音就偏左 |
| `P` | 開 / 關（2 秒淡入淡出） |
| `M` | 只關背景音樂，單獨聽行星之歌 |

跟隨行星時，畫面下方會顯示：`♪ Earth　D5 +14　592 Hz　角速度 = 平均的 1.01 倍`。

**不開 Unity 試聽**：執行 `python Assets/Docs/planet_song_preview.py`，然後打開 `Temp/StarrySkyPreview/planet_song_preview.wav`。每 4 秒換一顆行星當主角（水星 → 海王星），播放速度 20 天/秒。

## 3. 原理

### 3.1 克卜勒的「天體音樂」

克卜勒在 1619 年的《世界的和諧》裡，量了每顆行星在**近日點和遠日點的角速度**，發現它們的比例接近音樂的音程。例如土星的比例接近大三度，地球只有 16:15（一個半音，mi–fa）。他還半開玩笑地說，地球唱的 mi–fa 就是 *miseria, fames*（悲慘、飢荒）。

這個元件做的就是同一件事，只不過角速度是 N-body 模擬**當下**算出來的，不是查表。

### 3.2 音高公式

```
f = 參考音高 × (n / n_地球)^spread × (ω / n)
    └ 決定是哪個音 ┘└─── 行星之間 ───┘ └ 軌道上的起伏 ┘
```

| 符號 | 意思 | 怎麼算 |
| --- | --- | --- |
| ω | 瞬時角速度（弧度/天） | `|r × v| / r²`：角動量 ÷ 距離²（r、v 是相對太陽的位置與速度） |
| a | 半長軸 | vis-viva 公式 `v² = μ(2/r − 1/a)` → `1/a = 2/r − v²/μ` |
| n | 平均角速度 | 克卜勒第三定律 `n = sqrt(μ / a³)` |
| n_地球 | 參考 | `2π / 365.25` |
| spread | 行星之間差距的壓縮 | 預設 0.4 |

**為什麼要分成兩部分？**

- 水星和海王星的平均角速度差 684 倍，等於 **9.4 個八度**。照真實比例的話，海王星會低到 3.6 Hz，根本聽不到。所以「行星之間」的差距用 `^0.4` 壓縮成大約 4 個八度（76 ~ 1038 Hz）。
- 「同一顆行星在軌道上的起伏」`ω / n` **不壓縮**，保留真實比例，克卜勒的音程才聽得出來。

### 3.3 每顆行星的音高（`planet_song_preview.py` 算的）

| 行星 | 週期（天） | 平均 | 近日點 | 遠日點 | 起伏 |
| --- | --- | --- | --- | --- | --- |
| 水星 | 88 | 1038 Hz（C6） | 1610 Hz | 699 Hz | 1444 音分（一個八度多） |
| 金星 | 225 | 713 Hz（F5） | 723 Hz | 704 Hz | 47 音分（幾乎不動，軌道很圓） |
| 地球 | 365 | 587 Hz（D5） | 607 Hz | 568 Hz | 116 音分（一個半音：mi–fa） |
| 火星 | 687 | 456 Hz（A♯4） | 553 Hz | 380 Hz | 649 音分（約五度） |
| 木星 | 4332 | 218 Hz（A3） | 241 Hz | 198 Hz | 339 音分（約小三度） |
| 土星 | 10786 | 152 Hz（D♯3） | 170 Hz | 136 Hz | 392 音分（約大三度，和克卜勒算的一樣） |
| 天王星 | 30772 | 100 Hz（G2） | 109 Hz | 91 Hz | 317 音分 |
| 海王星 | 60347 | 76 Hz（D♯2） | 78 Hz | 74 Hz | 78 音分 |

起伏的大小只由**離心率**決定：`ω_近 / ω_遠 = ((1+e)/(1−e))²`。軌道越扁，音高起伏越大。

注意：模擬裡所有天體都從**近日點**出發，所以剛按 Play 時每顆行星都在最高音，之後才慢慢往下。

### 3.4 音量與左右

- **距離**：最近的行星權重 = 1，其他是 `(最近距離 / 自己的距離)^2`，再墊上一個最低值 `backgroundLevel`（0.15）。所以跟隨誰就主要聽到誰，其他行星保留一點當背景和聲。
- **防止爆音**：所有音量加起來超過 1 時，整體一起壓回 1。
- **左右**：`Camera.WorldToViewportPoint` 算出行星在畫面上的 x（0 ~ 1），換成聲像 -1 ~ +1，用等功率聲像分到左右聲道。

### 3.5 即時合成

背景音樂是事先算好的；行星之歌要跟著模擬變化，所以在 Unity 裡**即時**產生聲音。用的是 `OnAudioFilterRead`：Unity 的音訊執行緒每次需要聲音時（大約每 20 毫秒）就呼叫它，由我們把一段取樣填進去。詳見 [聲音合成入門教學.md](聲音合成入門教學.md) 第 13 節。

| 執行緒 | 做什麼 |
| --- | --- |
| 主執行緒（`Update`，每幀） | 讀物理狀態 → 算每顆行星的**目標**音高、音量、聲像 |
| 音訊執行緒（`OnAudioFilterRead`） | 從目前值**平滑地滑到**目標值，逐一取樣累加相位、算正弦波 |

兩邊分開是因為音訊執行緒**不能呼叫 Unity API**（不能讀 Transform、Camera），而且一定要準時交出聲音，不然會爆音、斷音。

## 4. 可調參數（Play 中選 Simulator 底下的 **Planet Song** 子物件）

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| Volume | 0.12 | 整體音量（2026-11-01 從 0.25 調小） |
| Muted | 關 | 靜音（等同 `P` 鍵） |
| Background Level | 0.15 | 遠處行星的最低音量。0 = 只聽最近的那顆；1 = 全部一樣大聲 |
| Distance Power | 2 | 越大，最近的行星越突出 |
| Stereo Width | 0.7 | 左右聲道分開的程度 |
| Fade Seconds | 2 | 開關時的淡入淡出秒數 |
| Reference Pitch | 587.33 | 地球的平均音高（D5，和背景音樂同調） |
| Reference Period Days | 365.25 | 參考週期 |
| Spread | 0.4 | 行星之間的差距：1 = 真實比例（外行星會低到聽不到），越小越擠在一起 |
| Kepler Wobble | 開 | 音高跟著瞬時角速度起伏；關掉 = 每顆行星固定在平均音高 |
| Snap To Scale | 關 | 對齊到 D 小調五聲音階：和背景音樂比較和諧，但音高會一格一格跳，聽不到連續的滑動 |
| Glide Seconds | 0.15 | 音高變化的平滑時間 |
| Brightness | 0.35 | 泛音量：0 = 純正弦波（像音叉），越大越亮 |
| Show Label | 開 | 畫面下方顯示音名與頻率 |

> 這個元件是執行時才掛上去的，**停止 Play 後數值會還原**。調到喜歡的數值後請告訴我，我會改成預設值。

## 5. 已知限制與下一步

- **和背景音樂可能不和諧**：行星的音高是連續的物理量，不在背景音樂的音階上。覺得刺耳時可以按 `M` 關掉背景音樂，或打開 **Snap To Scale**。
- 播放速度 1 天/秒時，外行星的音高幾乎不動（木星要 72 分鐘才走一圈）；想聽起伏要加速（`4`、`5`）。
- 衛星不發聲。如果要做，可以讓跟隨行星時改成播它的衛星（木衛一、二、三是 1:2:4 的軌道共振，聽起來會是八度關係）。
- Claude 聽不到聲音，也還沒在 Unity 裡執行過：`OnAudioFilterRead` 的實際音量、左右聲道、會不會斷音都還沒確認。
