# 太陽視覺效果說明（電漿表面 + 日冕 + Bloom）

最後更新：2026-10-26

太陽原本只是「預設 Lit 材質 + 黃色」的球，被 Directional Light 照亮，看起來不像會發光。
現在由 `SunVisual` 元件把它換成三層效果：

| 層 | 做法 | 檔案 |
| --- | --- | --- |
| 1. 發光 | 顏色用 HDR（亮度 > 1）+ URP Bloom（預設 Threshold 1、Intensity 1、Scatter 0.6） | `SunVisual.SetupBloom()` |
| 2. 表面電漿 | 球體換成自訂 Unlit Shader：流動噪聲 + 臨邊昏暗 | `Assets/Shaders/SunSurface.shader` |
| 3. 日冕 | 一張永遠面向相機的 Quad，畫放射狀、往外流動的光芒 | `Assets/Shaders/SunCorona.shader` |

共用的噪聲函式放在 `Assets/Shaders/SunNoise.cginc`。

---

## 1. 怎麼掛上去的

`SolarSystemBuilder` 建立天體時，遇到**沒有 parent 的天體（太陽）**就加上 `SunVisual`：

```csharp
if (sunVisual) created[p.name].gameObject.AddComponent<SunVisual>();
```

- 在 Simulator 物件的 `SolarSystemBuilder` 上取消勾選 **外觀 > Sun Visual**，就會回到原本的樣子。
- 只影響畫面，物理、CSV 完全不變。

`SunVisual.Start()` 做三件事：

1. 太陽的材質換成 `StarrySky/SunSurface`，關掉陰影。
2. 建立子物件 `Corona`（Quad），材質 `StarrySky/SunCorona`；`LateUpdate` 每幀把它轉成和相機同方向（billboard）。
3. 若目前使用 URP，建立全域 Volume 並加 Bloom，同時打開 Main Camera 的 Post Processing。

`SunVisual` 是 Play 時才加上去的，所以**只有 Play 中**才能在 Hierarchy 選 Sun 看到它。
它的所有欄位（日冕大小、亮度、Add Bloom 開關、Bloom 三個參數）都在 `LateUpdate` 每幀套用，改了立刻生效；
但停止 Play 後會回到程式裡的預設值，調好的數值要寫回 `SunVisual.cs`。

## 2. 表面電漿（SunSurface.shader）

### 2.1 fBm 噪聲
`sunFbm()` 把 5 層 value noise 疊起來，每層頻率 ×2、振幅 ÷2，得到有大有小的雲狀紋理。

### 2.2 Domain warping（電漿感的關鍵）
不是直接取 `fbm(p)`，而是先用另外三組噪聲算出一個位移 `warp`，再取 `fbm(p + warp)`。
座標被扭曲之後，紋理會出現拉長、捲曲的絲狀結構，看起來像翻騰的電漿，而不是普通的雲。
`warp` 的三組噪聲各自隨時間往不同方向移動，所以整個表面會持續流動。

### 2.3 米粒組織
再疊一層高頻噪聲（×8），模擬太陽表面細小的對流胞。

### 2.4 臨邊昏暗（limb darkening）
真實的太陽邊緣比中央暗、偏紅。用 `mu = dot(法線, 視線方向)`：中央 mu ≈ 1，邊緣 mu → 0，
再用 `pow(mu, _LimbPower)` 在表面色和 `_LimbColor` 之間插值。球體感會強很多。

### 2.5 可調參數（選太陽 → 材質，執行中可即時調）

| 參數 | 說明 |
| --- | --- |
| 亮部 / 暗部 / 邊緣顏色 | HDR 顏色，亮度超過 1 的部分會被 Bloom 抓到 |
| 電漿細節大小 `_NoiseScale` | 越大紋理越細碎 |
| 扭曲強度 `_WarpStrength` | 0 = 普通雲；越大越捲曲 |
| 流動速度 `_FlowSpeed` | 以真實時間計算，和模擬播放速度無關 |
| 臨邊昏暗程度 `_LimbPower` | 越大邊緣暗得越多 |

## 3. 日冕（SunCorona.shader）

### 3.1 為什麼用一張 Quad
相機是俯視的，太陽在畫面上永遠是一個圓盤，所以一張正對相機的平面就足夠了，比做一個體積效果便宜很多。
Quad 放在太陽中心，內側被太陽球體擋住（深度測試），只會看到球外的部分。

### 3.2 計算方式
以太陽半徑為單位，`r = 1` 是太陽表面：

| 成分 | 公式概念 | 效果 |
| --- | --- | --- |
| 整體光暈 `glow` | `exp(-(r-1) × 衰減)` | 越外面越暗 |
| 光芒 `filaments` | `fbm(方向 × 光芒數量, log(r) − 時間)` | 放射狀細絲，且不斷往外流 |
| 外輪廓擾動 `wobble` | 依角度改變衰減速度 | 日冕不是正圓 |
| 表面亮環 `rim` | `exp(-(r-1) × 18)` | 緊貼表面的一圈亮邊 |
| 邊緣淡出 | `smoothstep` | 看不到 Quad 的方框 |

- 角度用 `(cos θ, sin θ)` 當噪聲座標，而不是 θ 本身，所以 0° / 360° 不會有接縫。
- 徑向用 `log(r)`：靠近表面的細節比較密，往外拉長，比較像真的日冕。
- 混合模式是 **Additive**（`Blend One One`），光只會疊加，不會擋住後面的東西。

### 3.3 可調參數

| 位置 | 參數 | 說明 |
| --- | --- | --- |
| `SunVisual` | Corona Size | 日冕延伸到幾倍太陽半徑（預設 4） |
| `SunVisual` | Corona Intensity | 整體亮度 |
| Corona 材質 | 內圈 / 外圈顏色 | 內白黃、外橘紅 |
| Corona 材質 | 衰減速度 | 越大日冕越短 |
| Corona 材質 | 光芒數量 / 銳利度 | 光芒條數與粗細 |
| Corona 材質 | 往外流動速度 | |

## 4. Bloom 與 URP（重要）

Bloom 是 URP 的後處理效果，**只在專案真的使用 URP Pipeline Asset 時才有效**。

檢查時發現：`ProjectSettings/GraphicsSettings.asset` 與 `QualitySettings.asset` 指向的 URP Asset
（`Mobile`、`PC` 兩個品質等級）**在 Assets 裡找不到檔案**。這種情況下 Unity 會退回 Built-in 管線，
Bloom 不會出現，Console 會印出 `[SunVisual] 目前沒有使用 URP Pipeline Asset` 的警告。

兩支太陽 Shader 刻意寫成 URP 和 Built-in 都能畫，所以沒有 Bloom 時電漿與日冕仍然看得到，只是少了溢光。

**修復方式（約 1 分鐘）：**（2026-10-26 已重建為 `Assets/Settings/PC_RPAsset.asset`）

1. Project 視窗右鍵 → **Create > Rendering > URP Asset (with Universal Renderer)**，例如放在 `Assets/Settings/`。
2. 在該 Asset 的 Inspector 勾選 **Quality > HDR**。
3. **Edit > Project Settings > Graphics** → Default Render Pipeline 指定這個 Asset。
4. **Project Settings > Quality** → 每個品質等級（Mobile、PC）的 Render Pipeline Asset 也指定它。
5. **File > Save Project**，設定才會寫進 `ProjectSettings/`，git 才看得到。
6. 按 Play，Console 不再出現警告，太陽周圍會有 Bloom。

觀念說明見 [Shader與URP入門教學.md](Shader與URP入門教學.md) 第 1、3 節。

注意：切到 URP 後，`TrailRenderer` 用的 `Sprites/Default` 與行星的預設材質都還能用。

## 5. 已知限制與下一步

- **Shader.Find**：打包成執行檔時，若 Shader 沒被任何資源引用，`Shader.Find` 可能找不到。
  解法同 [TrailRenderer教學.md](TrailRenderer教學.md) 第 6 節：加到 Graphics Settings 的 Always Included Shaders。
- **拉遠時**：跟隨海王星等外圈行星時，太陽只剩幾個像素，日冕跟著變小，屬正常現象。
- **光源方向**：行星仍由 Directional Light 照亮，亮面不一定朝向太陽。改用原點的 Point Light 時，
  URP 光照是 1/d² 衰減，外圈行星會幾乎全黑，需要另外調整，因此這次沒有改。
- 可能的下一步：Particle System 做日珥、Lens Flare (SRP) 做鏡頭眩光。
