# Starry Sky 專案結構

用 Unity 實作的太陽系 N-body 重力模擬：太陽、八大行星與 20 顆主要衛星互相吸引，用 Velocity Verlet 積分推進。
天體資料全部來自 `Planets.csv`（軌道、大小、外觀 Prefab、自轉週期）；畫面上有電漿太陽與體積日冕、程序化行星、從太陽來的光照與星空背景，
可以調整播放速度、點選天體讓相機跟隨，並切換六種視角。

最後更新：2026-10-27

## 4. 主場景 N-body.unity

| 物件 | 元件 | 說明 |
| --- | --- | --- |
| **Simulator** | NBodySimulator | dt = 0.001 天、播放 30 天/秒、每幀最多 2000 步、1 AU = 10 Unity 單位、每 100 模擬天印一次能量誤差 |
| | SolarSystemBuilder | 讀 `Planets.csv`；外觀（Use Prefabs、Sun Visual、Space Environment）、自轉（Add Spin、上限 1 天/秒）、軌跡（0.3 圈） |
| | TimeControlUI | 右上角速度面板 |
| | CameraFocus | 左上列表、左下視角面板，控制 Main Camera |
| **Main Camera** | Camera | 初始位置 (0, 35, 0)，X 軸轉 90° 往下看（看到火星以內） |
| **Directional Light** | Light | Play 時被 `SpaceEnvironment` 關掉；所有天體的光都從太陽位置算 |

天體（太陽、行星、衛星）**不存在場景中**，是按下 Play 時由 SolarSystemBuilder 依 CSV 動態產生的。
`SunVisual`（Sun.prefab 上）、`BodySpin`、`SpaceEnvironment` 也是執行時才出現，Play 中才能在 Inspector 調整，停止後數值會還原。

## 5. 執行流程

```
按下 Play
│
├─ Awake   SolarSystemBuilder
│          ├─ 掛 SpaceEnvironment（Space Environment 開）；讀 Resources/Materials/SimpleBody
│          ├─ 讀 Resources/Planets.csv → PlanetSpec.ParseCsv()
│          ├─ 逐列建立天體（parent 要排在前面）
│          │    外觀：prefab 欄有填 → Resources.Load + Instantiate；否則純色球體（SimpleBody 材質）
│          │    太陽（沒有 parent）：Sun.prefab 已含 SunVisual；純色球時另外加 SunVisual
│          │    位置 = parent 位置 + 近日點距離；速度 = parent 速度 + vis-viva 速度（逆行則反向）
│          │    TrailRenderer（有公轉週期才加）、rotationPeriod ≠ 0 → 掛 BodySpin、CelestialBody
│          ├─ NBodySimulator.RemoveCenterOfMassDrift()   總動量歸零
│          └─ NBodySimulator.Initialize()                 初始加速度、初始能量
│
├─ Start   TimeControlUI、CameraFocus  初始化（記錄天體列表、初始相機高度與視野）
│          SpaceEnvironment            複製 Starfield 材質、環境光改 Flat、找出 Directional Light
│          SunVisual                   用 Prefab 的材質與 Corona（沒有就自己建立）、（URP 下）建立 Bloom Volume
│
└─ 每一幀
   ├─ Update      TimeControlUI       讀鍵盤 → 改 daysPerSecond / 暫停
   │              CameraFocus         讀滑鼠 → 點選天體 / 滾輪縮放 / 右鍵拖曳旋轉 / Esc / V 切視角
   │              NBodySimulator      累積時間 → 跑 N 步 Velocity Verlet → 更新 Transform 位置
   │              SolarSystemBuilder  依播放速度更新軌跡長度
   ├─ LateUpdate  CameraFocus         依視角算出相機位置與方向，切換時 Lerp / Slerp 過渡
   │              SunVisual           設定全域 _StarrySkySunPos（所有 Shader 的光源）、日冕大小與亮度、Bloom
   │              BodySpin            依這一幀推進的模擬天數繞自轉軸轉（有上限）
   │              SpaceEnvironment    星空開關與亮度、相機背景、環境光、Directional Light 開關
   └─ OnGUI       TimeControlUI       右上角面板
                  CameraFocus         左上列表、左下視角面板
```

## 6. 腳本職責

| 腳本 | 負責 | 主要欄位 / 方法 |
| --- | --- | --- |
| `CelestialBody` | 一顆天體的物理狀態 | `mass`、`position`、`velocity`（Vec3d）、`parent`、`orbitScale`、`displayColor`（列表文字顏色） |
| `NBodySimulator` | 物理核心 | `Step()` Velocity Verlet、`ComputeAccelerations()` O(N²) 重力、`SimulatedDays`、`TotalEnergy()`、`TotalAngularMomentum()`、`RemoveCenterOfMassDrift()`、`SyncTransforms()` 物理座標 → 畫面座標 |
| `PlanetSpec` | CSV 一列 | `ParseCsv()`：逗號或分號分隔、`#` 註解、錯誤列略過並報錯；第 8 欄以後都可省略 |
| `SolarSystemBuilder` | 建立場景 | 初始條件計算、`LoadPrefab()` 依 CSV 載入外觀、軌跡 `UpdateTrailTimes()`、掛 `BodySpin` / `SunVisual` / `SpaceEnvironment` |
| `TimeControlUI` | 播放速度 | `+`/`-`、`1`~`6`、空白鍵、`H`；量測實際速度 |
| `CameraFocus` | 相機與列表 | `Focus()`、`GoHome()`、`SetView()` 切換視角、`ComputeView()` 軌道相機、`FrameHeight()` 自動縮放、`Pick()` 點擊選取 |
| `SunVisual` | 太陽外觀（只影響畫面） | `surface`、`corona`、`coronaSize`、`coronaIntensity`、`SetupBloom()` |
| `BodySpin` | 自轉（只影響畫面） | `rotationPeriodDays`；上限讀 `SolarSystemBuilder.maxSpinDaysPerSecond` |
| `SpaceEnvironment` | 太空環境（只影響畫面） | `starfield`、`starBrightness`、`milkyWay`、`backgroundColor`、`ambientColor`、`disableDirectionalLights` |
| `Vec3d` | 向量運算 | double 精度；`ToVector3(scale)` 轉成 Unity 顯示座標 |

## 7. 單位與座標

| 量 | 單位 |
| --- | --- |
| 距離 | AU（天文單位） |
| 質量 | 太陽質量 |
| 時間 | 天 |
| G | 2.959122082855911 × 10⁻⁴ AU³ / (M☉ · day²) |

- **物理**全部用 `Vec3d`（double）；只有更新畫面時才轉成 Unity 的 `Vector3`（float）。
- **軌道面**是 XZ 平面，y 朝上；從上方看是逆時針公轉。
- **顯示比例**：1 AU = 10 Unity 單位。衛星與母星的顯示距離再乘上 CSV 的 `orbitScale`（只影響畫面）。
- **星球大小**（`displayRadius`）純粹是為了好看，與真實大小無關。Prefab 的根物件直徑都是 1，由 `displayRadius × 2` 縮放。
- **自轉軸**：Prefab 根物件的 local y（傾角做在 Rotation 的 z 軸）。
- **光源**：所有 StarrySky Shader 都用全域 `_StarrySkySunPos` 算光的方向，不用 Unity 的 Light。

## 8. 資料：Planets.csv

```
name,parent,mass,a,e,displayRadius,color,orbitScale,retrograde,prefab,rotationPeriod
```

| 欄位 | 影響 | 說明 |
| --- | --- | --- |

| `rotationPeriod` | 只影響畫面 | 恆星自轉週期（天）；太陽與八大行星有填，衛星空白 = 不自轉 |

| 類別 | 天體 |
| --- | --- |
| 恆星 | 太陽 |
| 行星 | 水星、金星、地球、火星、木星、土星、天王星、海王星 |
| 衛星 | 月球；火衛一、二；木衛一～四；土衛一～六、土衛八；天衛一～五；海衛一（逆行） |

- [ ] 場景檔中仍留有舊欄位（`sunDisplayRadius`、`planets`、`trailSeconds`），不影響執行，Unity 存一次場景就會清掉。

### 模擬的簡化

- 所有天體從近日點出發，一開始排成一直線，近日點方向也都相同。若要真實排列，可改用 NASA JPL Horizons 的位置與速度。
- 沒有軌道傾角，所有軌道都在同一平面（天王星衛星、海衛一的真實軌道差很多）。
- 光不隨距離衰減，海王星和水星一樣亮；天體之間沒有影子（只有土星環的影子）。
- 打包成執行檔時，`Shader.Find("Sprites/Default")`（軌跡）可能找不到 Shader，見 [TrailRenderer教學.md](TrailRenderer教學.md) 第 6 節。
