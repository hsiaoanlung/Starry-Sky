# Starry Sky 專案結構

用 Unity 實作的太陽系 N-body 重力模擬：太陽、八大行星與 20 顆主要衛星互相吸引，用 Velocity Verlet 積分推進，可調整播放速度、點選天體讓相機跟隨。

最後更新：2026-10-26

---

## 3. 主場景 N-body.unity

| 物件 | 元件 | 說明 |
| --- | --- | --- |
| **Simulator** | NBodySimulator | dt = 0.001 天、播放 30 天/秒、每幀最多 2000 步、1 AU = 10 Unity 單位、每 100 模擬天印一次能量誤差 |
| | SolarSystemBuilder | 讀 `Planets.csv`，軌跡長度 = 0.3 圈 |
| | TimeControlUI | 右上角速度面板 |
| | CameraFocus | 左側列表，控制 Main Camera |
| **Main Camera** | Camera | 初始位置 (0, 35, 0)，X 軸轉 90° 往下看（看到火星以內） |
| **Directional Light** | Light | |

天體（太陽、行星、衛星）**不存在場景中**，是按下 Play 時由 SolarSystemBuilder 依 CSV 動態產生的。

## 4. 執行流程

```
按下 Play
│
├─ Awake   SolarSystemBuilder
│          ├─ 讀 Resources/Planets.csv → PlanetSpec.ParseCsv()
│          ├─ 逐列建立天體：球體 + TrailRenderer + CelestialBody
│          │    太陽（沒有 parent）另外掛 SunVisual
│          │    位置 = parent 位置 + 近日點距離
│          │    速度 = parent 速度 + vis-viva 速度（逆行則反向）
│          ├─ NBodySimulator.RemoveCenterOfMassDrift()   總動量歸零
│          └─ NBodySimulator.Initialize()                 初始加速度、初始能量
│
├─ Start   TimeControlUI、CameraFocus 初始化（記錄天體列表、初始相機高度）
│          SunVisual   換材質、建立日冕 Quad、（URP 下）建立 Bloom Volume
│
└─ 每一幀
   ├─ Update      TimeControlUI   讀鍵盤 → 改 daysPerSecond / 暫停
   │              CameraFocus     讀滑鼠 → 點選天體 / 滾輪縮放 / Esc
   │              NBodySimulator  累積時間 → 跑 N 步 Velocity Verlet → 更新 Transform
   │              SolarSystemBuilder  依播放速度更新軌跡長度
   ├─ LateUpdate  CameraFocus     相機移到目標正上方
   │              SunVisual       日冕 Quad 轉向相機
   └─ OnGUI       TimeControlUI   右上角面板
                  CameraFocus     左側列表
```

## 5. 腳本職責

| 腳本 | 負責 | 主要欄位 / 方法 |
| --- | --- | --- |
| `CelestialBody` | 一顆天體的物理狀態 | `mass`、`position`、`velocity`（Vec3d）、`parent`、`orbitScale` |
| `NBodySimulator` | 物理核心 | `Step()` Velocity Verlet、`ComputeAccelerations()` O(N²) 重力、`TotalEnergy()`、`TotalAngularMomentum()`、`RemoveCenterOfMassDrift()`、`SyncTransforms()` 物理座標 → 畫面座標 |
| `PlanetSpec` | CSV 一列 | `ParseCsv()`：逗號或分號分隔、`#` 註解、錯誤列略過並報錯 |
| `SolarSystemBuilder` | 建立場景 | 初始條件計算、建立球體與軌跡、`UpdateTrailTimes()` |
| `TimeControlUI` | 播放速度 | `+`/`-`、`1`~`6`、空白鍵、`H`；量測實際速度 |
| `CameraFocus` | 相機與列表 | `Focus()`、`GoHome()`、`FrameHeight()` 自動縮放、`Pick()` 點擊選取 |
| `SunVisual` | 太陽外觀（只影響畫面） | `coronaSize`、`coronaIntensity`、`SetupBloom()`；詳見 [太陽視覺效果說明.md](太陽視覺效果說明.md) |
| `Vec3d` | 向量運算 | double 精度；`ToVector3(scale)` 轉成 Unity 顯示座標 |

## 6. 單位與座標

| 量 | 單位 |
| --- | --- |
| 距離 | AU（天文單位） |
| 質量 | 太陽質量 |
| 時間 | 天 |
| G | 2.959122082855911 × 10⁻⁴ AU³ / (M☉ · day²) |

- **物理**全部用 `Vec3d`（double）；只有更新畫面時才轉成 Unity 的 `Vector3`（float）。
- **軌道面**是 XZ 平面，y 朝上；從上方看是逆時針公轉。
- **顯示比例**：1 AU = 10 Unity 單位。衛星與母星的顯示距離再乘上 CSV 的 `orbitScale`（只影響畫面）。
- **星球大小**（`displayRadius`）純粹是為了好看，與真實大小無關。

- 所有天體從近日點出發，一開始排成一直線，近日點方向也都相同。若要真實排列，可改用 NASA JPL Horizons 的位置與速度。

- 打包成執行檔時，`Shader.Find("Sprites/Default")` 可能找不到 Shader，見 [TrailRenderer教學.md](TrailRenderer教學.md) 第 6 節。
