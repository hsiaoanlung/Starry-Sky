# 相機與天體列表說明

按下 Play 後，畫面**左側**是天體列表，可以選擇要跟隨的天體；相機會飛過去，從正上方跟著它，並自動縮放到適合的範圍。
程式：`Assets/Script/N-body/CameraFocus.cs`（掛在場景的 **Simulator** 物件上）。

播放速度的控制在畫面**右上角**，見 [時間控制按鍵說明.md](時間控制按鍵說明.md)。

---

## 1. 操作一覽

| 操作 | 功能 |
| --- | --- |
| 點左側列表的名字 | 相機飛到該天體並跟隨 |
| 點畫面上的星球 | 同上（點在星球 25 像素內就算點中） |
| 滑鼠滾輪 | 縮放：往上滾拉近、往下滾拉遠 |
| `Esc` 或「重設視角」按鈕 | 回到初始視角（太陽系中心正上方） |

- 列表中，衛星會縮排在所屬行星下方，名字左邊的圓點是星球的顏色。
- 目前跟隨的天體會以**金色粗體**顯示，列表標題也會顯示「目前：xxx」。
- 滑鼠在列表上時，滾輪捲動的是列表，不會縮放畫面。
- 暫停（空白鍵）時仍可切換目標與縮放。
- 按鍵或點擊沒反應時，先用滑鼠點一下 Game 視窗讓它取得焦點。

---

## 2. 自動縮放的規則

選取天體時，相機高度會自動計算，讓需要看的範圍剛好放進畫面：

1. **範圍** = 以下兩者取大的：
   - 星球顯示半徑 × `Radius Multiplier`（預設 6）
   - 最遠那顆衛星在畫面上與它的距離（已包含 `orbitScale` 放大）
2. **相機高度** = 範圍 × `Framing Margin`（預設 1.4，留白）÷ tan(視角 / 2)

所以：

| 選取 | 範圍由誰決定 | 相機高度（約） |
| --- | --- | --- |
| 太陽 | 最遠的行星（海王星） | 740，看到整個太陽系 |
| 土星 | 土衛八 Iapetus | 21 |
| 木星 | 木衛四 Callisto | 7.7 |
| 地球 | 月球 | 1.6 |
| 火星 | 火衛二 Deimos | 1.1 |
| 水星、衛星等 | 星球本身 × 6 | 0.1 ~ 1.2 |
| 初始視角（Esc） | 場景中相機原本的高度 | 35，看到火星以內 |

自動算好之後，可以再用滾輪調整（每格 1.25 倍）。切換到新目標時，縮放會重設。

### 為什麼選太陽會看到整個太陽系

太陽的「衛星」就是所有 `parent = Sun` 的行星，所以範圍由最遠的海王星決定。想看內行星，按 `Esc` 回初始視角，或選太陽後用滾輪拉近。

---

## 3. 跟隨的運作方式

- **飛過去**：切換目標時，相機在 `Transition Time`（預設 0.8 秒）內，從目前位置平滑移到新目標上方。
- **鎖定**：到達後，相機每幀直接放在目標正上方，所以就算目標跑得很快（例如月球、每秒 100 天的地球），也不會落後或甩出畫面。
- **只移動、不旋轉**：相機永遠從正上方往下看，畫面右方是 +x、上方是 +z，和初始視角相同。
- **更新時機**：相機在 `LateUpdate` 移動，也就是 `NBodySimulator` 在 `Update` 更新完星球位置之後，畫面才不會抖動或慢一幀。
- **時間**：鏡頭的移動用真實時間（`Time.unscaledDeltaTime`），不受暫停影響。

### 跟隨衛星時的畫面

鎖定月球時，月球固定在畫面中央，看起來會像是**地球繞著月球轉**，背景的軌跡也會快速移動。這是相對運動的正常結果，換成跟隨地球就會看到月球繞地球。

### Near / Far Clip 自動調整

放大到衛星時，相機離星球只有零點幾個單位，比預設的 near clip（0.3）還近，星球會被切掉。所以程式每幀都會調整：

- near clip = 相機高度 × 0.01（最小 0.001）
- far clip = max(1000, 相機高度 × 3)

---

## 4. 搭配播放速度

放大到衛星系統時，原本的 30 天/秒通常太快（見 [時間控制按鍵說明.md](時間控制按鍵說明.md) 第 3 節）。建議：

| 跟隨 | 建議按鍵 |
| --- | --- |
| 火星（看火衛一、二） | `1`（0.1 天/秒） |
| 木星、土星、天王星 | `1` 或 `2`（0.1 ~ 1 天/秒） |
| 海王星 | `2`（1 天/秒） |
| 地球（看月球） | `3`（5 天/秒） |
| 太陽、行星本身 | `4` 以上 |

---

## 5. 自訂

在 Hierarchy 選 **Simulator** → Inspector 的 **Camera Focus**：

| 欄位 | 預設 | 說明 |
| --- | --- | --- |
| Simulator | Simulator | 取得天體列表的來源 |
| Cam | Main Camera | 要控制的相機 |
| Framing Margin | 1.4 | 自動縮放時的留白倍數，越大看得越廣 |
| Radius Multiplier | 6 | 沒有衛星的天體，畫面範圍是半徑的幾倍 |
| Transition Time | 0.8 | 切換目標的飛行時間（秒） |
| Zoom Step | 1.25 | 滾輪每格縮放倍數 |
| Pick Radius Pixels | 25 | 點擊畫面時，離星球幾像素內算點中 |
| Font Size | 15 | 列表字體大小 |
| Panel Width | 190 | 列表寬度（像素） |

初始視角的高度沿用場景中 **Main Camera** 的 Y 座標（目前 35）。想改初始範圍，直接改 Main Camera 的 Position Y 即可。

---

## 6. 已知限制

- 只有俯視角度，不能旋轉或傾斜相機。所有軌道都在同一平面，俯視最清楚。
- 點擊畫面時，若好幾顆星重疊在一起（例如從遠處看木星和它的衛星），會選到離滑鼠最近的那顆，可能不是想要的。這時用左側列表選比較準確。
- 列表與按鍵說明都是 IMGUI（`OnGUI`）畫的，適合開發與展示，不是正式遊戲 UI。
